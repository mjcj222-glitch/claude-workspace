# 유튜브 라이브 + 채팅 (가로에서도 채팅 유지)

## 문제

세로로 볼 땐 유튜브 앱이 위에 영상, 아래에 채팅을 보여줘서 편함.
근데 90도로 돌려서 전체화면으로 가면, 화면 비율을 맞추려고 영상만 꽉 채우고 채팅을 없애버림.
네이티브 앱(닫힌 소스)이라 이 동작 자체는 고칠 수 없음.

## 해결 방법

앱 대신 브라우저에서 영상+채팅을 직접 iframe 두 개로 띄우는 페이지를 만듦.
레이아웃을 유튜브가 아니라 이 페이지의 CSS가 정하기 때문에:

- 세로: 영상 위 / 채팅 아래 (기존 앱과 동일한 느낌)
- 가로: 영상 왼쪽 / 채팅 오른쪽, 둘 다 항상 보임
- "전체화면" 버튼은 영상 하나가 아니라 영상+채팅을 감싸는 전체 박스를 전체화면으로 만듦
  → 전체화면 안에서도 가로 레이아웃(영상+채팅)이 그대로 유지됨

## 쓰는 법

1. 이 폴더를 HTTPS로 열 수 있는 곳에 올림 (GitHub Pages 등)
2. 폰 브라우저(삼성 인터넷 또는 크롬)로 그 주소 열기
3. 유튜브 앱에서 라이브 영상 → 공유 → 링크 복사 → 이 페이지에 붙여넣고 "시작"
4. 화면 회전 → 자동으로 좌우 레이아웃으로 바뀜
5. "전체화면" 눌러서 몰입해서 보기

## 검증한 것 (Playwright, 로컬 서버 + 실제 라이브 영상으로 실행)

- 채팅 iframe이 다른 도메인(embed_domain)에서도 실제로 렌더됨 — 스크린샷으로 확인
- 세로(390×844, 일반 폰 비율): 영상 위 / 채팅 아래, 스크린샷 확인
- 가로 — **폴드7 펼친 화면 비율(약 874×787, 거의 정사각형 1.1:1)로 테스트.**
  커버 화면이 아니라 펼쳤을 때의 내부 화면 비율을 기준으로 맞춘 것.
  처음엔 `aspect-ratio: auto`로 잘못 둬서 영상이 찌그러지고 텍스트가 잘려 보이는 버그가 있었음
  (스크린샷으로 실제 확인) → `aspect-ratio: 16/9`를 유지한 채 폭/높이를 자동 계산하고
  세로 중앙 정렬(letterbox)하도록 고침 → 재검증해서 영상 안 잘리고 채팅도 온전히 보이는 것 확인
- "전체화면" 버튼 클릭 시 `document.fullscreenElement` 가 영상이 아니라 영상+채팅 래퍼 전체인 것 확인
  → 전체화면 안에서도 채팅이 사라지지 않는다는 뜻 (펼친 화면 비율에서도 재확인함)

## 알려진 한계

- **라이브 스트림 + 채팅 켜진 영상에서만 의미 있음.** 일반 VOD는 채팅 iframe이 비어 있음.
- 채팅을 **읽을 순 있지만 쓰려면 로그인 필요** — 유튜브 쪽 기본 제약, 여기서 우회하지 않음.
- 페이지 로드와 동시에(공유 링크로 바로 열었을 때) 자동재생이 브라우저 정책으로 막힐 수 있음.
  그럴 땐 영상 위 재생 버튼 한 번 탭.
- `screen.orientation.lock('landscape')` 은 크롬 계열에서만 되고 안 되면 조용히 무시됨 —
  안 돼도 손으로 돌리면 레이아웃은 똑같이 바뀜.
- 폴드7 커버 화면 vs 펼친 화면에서 가로 폭이 크게 다름. 채팅 폭을 고정 300px로 뒀는데,
  펼친 화면 가로 모드에서 너무 좁게/넓게 느껴지면 `index.html` 의
  `#chat { flex: 0 0 300px; }` 숫자만 바꾸면 됨.

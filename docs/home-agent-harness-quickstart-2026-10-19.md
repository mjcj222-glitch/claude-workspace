# 집 AI 에이전트 하네스 — 귀가 후 바로 시작

> 작성: 2026-10-19 · 상태: **구축 계획서** (설치/연동/자동 실행은 아직 진행하지 않음)

## 목표
- **집 PC를 꺼놔도** 연구·정리·후속 과제를 클라우드에서 계속 진행한다.
- 현재 **ChatGPT Pro X20**의 포함된 **dot + Codex Cloud** 사용량을 우선 활용한다.
- **추가 VPS/서버 비용 0원**, **별도 OpenAI API 호출/결제 없이 시작**한다. 단, 구독 사용량 한도·크레딧 정책은 적용된다.
- 조사·검증·개발·보고를 역할로 나누고, 작업 결과를 GitHub에 기록한다.

## 1단계 권장 아키텍처

```text
[나: PC/휴대폰에서 목표 지정]
             |
[ChatGPT dot: 총괄/예약 실행/장기 문맥]
      |                  |
[연구→교차 검증→보고]  [Codex Cloud: 코드/테스트]
      |                  |
      +---- [GitHub: 결과/코드/이력] ---+
                    |
       [집 PC: 선택적 로컬 작업]
       (로컬 작업 때만 켜기)
```

**중요:** '연구·검증·개발·보고'는 초기에 **논리적 역할 분담**이다. 독립 프로세스 4개가 항상 동시에 돌아가는 완성형 커스텀 멀티에이전트는 아니다. 먼저 1단계를 성공시키고, 필요 시 Codex 멀티에이전트/별도 하네스로 확장한다.

## 집에서 바로 할 체크리스트

- [ ] [ChatGPT dot](https://chatgpt.com/dots)에서 **현재 Pro 계정으로 접속**하고, 이 프로젝트의 장기 목표를 전달한다.
- [ ] [Codex](https://chatgpt.com/codex)에서 같은 ChatGPT 계정으로 로그인한다.
- [ ] Codex에서 GitHub 계정 연결 → `mjcj222-glitch/claude-workspace` 저장소를 사용할 **Codex Cloud 환경 생성 및 게시** (계정 UI에 보이는 절차대로).
- [ ] Codex Cloud에서 작은 **읽기/테스트 작업**을 실행하여 실제 클라우드 실행과 결과 확인이 가능한지 검사한다.
- [ ] dot이 **해당 Codex Cloud 환경에 작업을 생성**할 수 있는지 확인한다. 처음에는 '현재 파일 구조 조사 후 보고' 같은 읽기 전용 작업으로 테스트한다.
- [ ] dot에서 **정기 연구 작업** 설정(예: 한국시간 매일 오전 9시) → dot 프로필의 **Scheduled/예약됨**에서 일정 확인.
- [ ] GitHub 기록 권한이 연결되어 있다면 보고서 저장 테스트. 쓰기 권한/승인이 안 되면 보고서 초안만 만들고 수동 반영한다.
- [ ] 집 PC를 끈 상태에서 **예약 실행 기록·결과 보고**가 남는지 확인한다. 로컬 작업은 PC가 켜져 있어야 한다.

## dot에 처음 보낼 프롬프트 (복사해서 사용)

```text
너는 나의 개인 AI 연구실 총괄 에이전트다.
목표: 내가 지정한 주제를 장기적으로 조사하고, 새로운 사실이나 반론을 찾으면
추가 연구 과제를 만들고, 근거와 함께 결과를 기록한다.

작업을 다음 4개 역할로 나누어 수행해:
1. 기획: 연구 목표를 작은 과제로 분해하고 우선순위를 정한다.
2. 조사: 최신 자료와 원문/1차 출처를 찾고 날짜·URL을 기록한다.
3. 검증: 상충 자료와 반증을 찾아 사실/추정/의견을 분리한다.
4. 보고: 핵심 결론, 근거 URL, 미확인 사항, 다음 연구 과제를 간결히 정리한다.

매일 한국시간 오전 9시에 지난 24시간의 진전을 점검하고,
새로 확인된 사실·중복 제거 사항·다음 과제를 보고해 줘.
가능하다면 GitHub 저장소의 reports/YYYY-MM-DD/ 폴더에 Markdown으로 기록해.
접근 권한이 없으면 저장했다고 주장하지 말고 초안을 내게 보여줘.

코딩이 필요한 경우 Codex Cloud 환경으로 작업을 위임하되,
비용 발생, 공개 게시, 파일 대량 삭제, 외부 계정 변경은 반드시 먼저 승인받아.
구독 사용량 한도에 도달하면 멈추고 알린다.
```

## 역할별 규칙·결과물
- **총괄(dot):** 오늘 할 일·진행 상태·다음 과제.
- **연구:** 출처 원문 링크·발행일·핵심 사실.
- **검증:** 두 출처 이상 교차 확인, 반대 근거, 불확실성 표시.
- **개발(Codex Cloud):** 실험 코드와 테스트 결과, 변경 검토 후 반영.
- **보고:** `reports/YYYY-MM-DD/daily.md` 에 결론/출처/남은 질문/다음 단계 기록.

## 비용과 보안 주의
- **ChatGPT Pro 구독 ≠ 일반 OpenAI API 무제한 무료 사용권.** API 키 기반 자동화는 별도 과금이 될 수 있다.
- dot 첫 에이전트와 Codex Cloud는 해당 Pro 플랜의 **포함 사용량 내** 우선 사용한다. 한도 초과 시 추가 크레딧 구입은 선택사항이다. **무제한 24시간 연속 추론은 보장되지 않는다.**
- **GitHub Actions에 ChatGPT 로그인 쿠키·OAuth 토큰을 저장하거나 비공식 웹 자동화로 구독을 우회하지 말 것.**
- 연결 계정의 권한을 최소화하고, 비밀번호/API 키/사적인 자료는 **공개 저장소에 기록 금지**.
- 집 PC 로컬 파일을 건드려야 하는 작업만 별도 승인으로 연결한다. **PC가 꺼져 있을 때 로컬 프로그램 조작 불가**.
- 매일 연구는 일정·새 정보에 따라 **작업 단위로** 실행하고, 무한 재시도/무제한 탐색은 금지한다.

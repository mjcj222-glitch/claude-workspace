# claude-workspace

Claude Code와 함께 쓰는 개인 작업 공간입니다.
코드 프로젝트라기보다, Claude를 어떻게 쓰는지 정리해두고 필요한 문서와 실험을
쌓아가는 저장소에 가깝습니다.

## 지금 들어있는 것

| 파일 | 설명 |
| --- | --- |
| [`claude-소개.md`](./claude-소개.md) | Claude Code가 무엇을 할 수 있고 어떻게 일하는지에 대한 소개 문서 |
| `README.md` | 이 문서 |

## 시작하기

저장소를 받아옵니다.

```bash
git clone https://github.com/mjcj222-glitch/claude-workspace.git
cd claude-workspace
```

문서만 있는 저장소라 별도의 설치나 빌드 과정은 없습니다. 마크다운 파일을
편집기에서 바로 열어보시면 됩니다.

Claude Code로 이 저장소에서 작업하려면:

```bash
claude
```

## 이 저장소를 쓰는 방법

- Claude에게 시킬 일이나 반복해서 쓰는 지시를 문서로 남겨둡니다.
- 실험한 결과나 정리한 내용을 마크다운으로 쌓아둡니다.
- 파일이 늘어나면 주제별로 디렉터리를 나누고, 위의 표를 함께 갱신합니다.

## 브랜치

기본 브랜치는 `main`입니다. 작업은 별도 브랜치에서 진행한 뒤 병합합니다.

```bash
git switch -c 브랜치이름
```

## 라이선스

아직 라이선스를 지정하지 않았습니다. 별도 명시가 없는 한 모든 권리는 저장소
소유자에게 있습니다.

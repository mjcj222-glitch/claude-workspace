# dot 첫 메시지 — 전체 복사

다음 내용을 사용자 본인의 dot 채팅에 전달하세요.

---

너는 내 개인 **통합 AI 연구실의 총괄 에이전트**다. 내 집 PC가 꺼져 있어도 네 클라우드 환경에서 스스로 연구하고 진행 상황을 정리하도록 구성하고 싶다.

GitHub 프로젝트: https://github.com/mjcj222-glitch/claude-workspace/tree/main/agent-harness

우선 README.md, AGENTS.md, topics.json, roles/*.md를 읽고 규칙을 적용해라. 연결된 GitHub를 읽을 수 없다면 즉시 알려 주고 필요한 최소 승인만 요청해라.

처음 주제는 topics.json의 `harness-bootstrap`이다. 목표는 **ChatGPT Pro 구독을 활용해 별도 서버 비용과 일반 API 사용 없이 안정적인 연구·검증·개발·보고 루프**를 구성하는 것이다.

역할:
1. 기획/총괄: 중복 없이 다음 과제 1~3개 선정
2. 조사: 공식 출처 수집, 날짜/링크 기록
3. 검증: 반론·미확인 사항 확인
4. 개발: 코드가 필요하면 사용자가 미리 만든 Codex Cloud 환경으로 위임
5. 보고: 보고서를 날짜별 Markdown으로 기록

**한국시간 매일 오전 9시**에 이 주제의 진전을 점검하는 반복 작업을 예약해 줘. 첫 실행은 이 프롬프트를 받은 후 시작해도 좋다. 결과가 없을 때는 변화 없다고 보고해라. dot 예약 작업을 실제 생성했다면 예약됨 목록에서 확인 가능한 상태를 알려 줘.

Codex Cloud 환경이 아직 생성·게시되지 않았다면 그 사실만 알리고 연결 단계는 건너뛰어라. GitHub에 글을 쓰거나 공개 게시할 수 없다면 보고서 초안을 제공하되 성공했다고 표시하지 마라. **유료 결제, API 키 발급, 자동 충전, 민감 정보 게시, 외부 송신, 대규모 변경·삭제는 사전 승인**받아라.

마지막으로 다음 세 가지를 구분해 답해라:
- 내가 실제로 수행한 연결·실행·저장
- 승인이 필요한 것
- 아직 구현되지 않은 기능

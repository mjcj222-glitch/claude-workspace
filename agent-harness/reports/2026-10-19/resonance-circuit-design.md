# 잔향 회로 — 퍼즐 전투 시제품 설계
작성: 2026-10-19 KST. 상태: 구현 전 설계. 사용자 요청은 Crash Fever와 같은 재미를 추구하는 독자적인 퍼즐 게임이다.

## 조사와 선택
공식 [기본 설명](https://crashfever.com/faq/2022082523946/)과 [퀘스트 FAQ](https://crashfever.com/faq/faq_cat/faq6/)를 2026-10-19 확인했다. 원작은 탭으로 패널을 파괴하고 기본 3탭 후 공격하며, 큰 연결에서 특수 패널이 생긴다. 파티 스킬과 피버도 판과 전투에 개입한다. 아래 수치·규칙·세계관은 새 게임용 제안이며 원작 내부 구현의 재현이 아니다.
설계 가설: ‘큰 폭발을 본다’보다 ‘다음 폭발을 직접 준비한다’가 재도전 동기를 만든다.
별도 모델 GPT-6 Sol과 GPT-6.1 Sol의 아이디어를 비교했다. 잔향 연쇄와 탄두 반사 중 첫 버전에는 잔향만 채택한다. 탄두 반사는 별도 실험 후보로 남긴다. 외부 Claude/Gemini 엔진을 호출한 것은 아니다.

## 목표와 범위
- 제목: 잔향 회로 (임시명). 고장 난 유리 온실의 에너지 회로를 정화하는 독자적 기하학/식물/빛 테마.
- 모바일·데스크톱 브라우저 싱글플레이, 짧은 보스전 1개, 3명의 고정 기술자.
- 목표 플레이 길이 2–3분은 실측 전 가설이다. 실제 시간을 측정해 조정한다.
- 로그인, 네트워크 서버, 결제, 가챠, 외부 에셋 다운로드, 분석 추적 없음.
- 원작 캐릭터·음악·로고·이미지·문구·화면을 복제하지 않는다.
- 구현 범위는 agent-harness/games/resonance-circuit/ 아래 새 파일. 기존 앱 코드는 변경하지 않는다.

## 정확한 규칙
### 보드와 턴
- 6열×7행, 홀수 열이 반 칸 아래로 내려가는 hex 배치. 인접은 최대 6칸, 중력은 열 아래쪽.
- 3개 공격색과 회복색. 색마다 모양도 다르게 하여 색만으로 구분하지 않는다.
- 같은 색의 연결 묶음을 탭해 제거한다. 고립된 1개도 유효하다.
- 턴당 3탭. 제거 피해와 회복은 턴 끝에 정산한다. 예상 피해/회복과 남은 탭을 표시한다.
- 회복 상한 적용 → 보스 HP 정산 → 보스 사망이면 승리, 아니면 예고된 공격 → 플레이어 HP가 0이면 패배.
- 선택 미리보기는 포인터 누름/키보드 포커스로, 확정은 같은 대상에서 떼기/Enter. 드래그 취소 및 터치 스크롤 오작동 방지.

### 특수 패널
- 타일은 고유 ID, 색, 종류(normal/charge/bomb)를 갖는다.
- 최초 연결 묶음이 5–9개면 차지, 10개 이상이면 폭탄을 탭 위치에 1개 생성한다. 회복색은 생성하지 않는다.
- 폭발로 추가 제거된 개수는 생성 기준에 합산하지 않는다.
- 차지는 제거 시 기본 효과 + 고정 추가 피해. 폭탄은 자기와 인접 6칸을 제거하고 다른 폭탄도 연쇄 점화한다.
- 제거 집합은 ID 기준 중복 제거. 새 특수는 현 해소 과정에서 발동하지 않는다.
- 제거 → 새 특수 생성 → 중력 → 시드 난수 보충 순서. 전체 42칸과 생존 타일 순서를 유지한다.

### 독자적 잔향
- 공격색 최초 묶음 5개 이상 제거 시 그 묶음에 인접했고 최종 제거되지 않은 일반 공격 타일 최대 8개에 잔향을 남긴다. 안정적인 열/행 순으로 선정한다.
- 표식은 좌표가 아니라 타일 ID를 따라 낙하한다. 새로 보충된 타일과 새 특수는 같은 해소에서 표식 대상이 아니다.
- 다음 유효 탭의 최초 연결 묶음이 잔향 타일을 하나라도 포함하면, 이전 잔향 타일 전부를 추가 제거 대상에 넣는다. 이후 폭탄 연쇄도 처리한다.
- 다음 유효 탭이 잔향을 건드리지 않아도 이전 표식은 만료한다. 스킬 사용·미리보기·취소는 유효 탭이 아니므로 만료시키지 않는다.
- 이전 표식의 추가 제거가 새 잔향 생성 기준을 늘리지 않는다. 현재 최초 묶음으로만 새 표식을 만든다. 재귀 잔향 없음.
- 잔향은 턴 경계를 넘어 다음 유효 탭까지 유지한다. ‘다음 탭에 연결’ 텍스트와 모양을 표시한다.

### 기술자와 역전
- 3스킬: 파랑→빨강 변환(종류·ID·잔향 보존), 일반 공격 타일 최대2개를 폭탄으로, 일반 공격 타일 최대6개를 회복으로.
- 특수 덮어쓰기 금지. 회복 전환된 타일의 잔향은 제거한다. 후보 부족은 가능한 만큼만, 후보0이면 사용 불가·쿨다운 미소모.
- 1턴부터 사용 가능. T턴에 쓰면 T+3턴 시작에 재사용. 스킬은 탭을 소모하지 않는다. 스킬 뒤 자동 제거 없음.
- 과충전 게이지: 제거한 고유 타일 수로 축적, 임계값은 설정 파일. 턴 첫 탭 전만 수동 발동. 그 턴 피해2배, 회복 및 적 행동은 그대로. 발동 턴에는 게이지 획득 없음.
- 보스는 보통/강공격을 번갈아 사용하며 다음 공격 피해를 항상 표시. 시작 수치와 피해 배율은 한 설정 모듈에 모은다.
- 첫 판은 고정 시드와 큰 묶음이 보장된 시작 보드로 잔향 성공 기회를 제공한다. 재시작은 같은 시드/새 시드 선택 가능.

## 표현과 사용성
- 세로 중심, 짙은 남색 배경, 유리 패널과 민트/산호/금빛, 원작과 다른 화면 구성.
- 연결 범위→파괴→낙하→잔향 순서를 읽을 수 있게 표현. 큰 폭발만 짧은 흔들림, reduced-motion 지원.
- 소리는 기본 무음. 품질을 검증하기 전 거친 합성 효과음을 넣지 않는다. 시각만으로도 결과 이해 가능해야 한다.
- 첫 시작에 3단계 짧은 튜토리얼, 규칙 보기, 다시 시작, 승패 화면, 최대 연쇄·총 잔향 발동 수 표시.
- 해소 중 입력 잠금. 종료 상태 입력 무시. 키보드 이동/확정 및 명확한 포커스. 360px 폭 가로 넘침 금지.

## 개발 방식
- 가능한 최소 의존성: HTML/CSS/ES modules와 순수 JS 로직, node:test. 프로젝트에 기존 테스트 관례가 있으면 먼저 확인한다.
- 로직과 렌더링 분리. 게임용 시드 난수와 시각 효과 난수 분리.
- 실행 README, 고정 시드 테스트, 시제품 파일을 함께 추가한다.
- 공식 Codex Cloud 환경에서 실행. 환경 미확인 상태에서 구현·테스트 완료라고 표현하지 않는다.

## 검증 기준
1. hex 이웃/경계, 그룹 탐색, 1개 탭, 4/5/9/10 경계.
2. 폭탄 겹침/폭탄 연쇄/차지 각각1회, 새 특수 즉시 점화 금지.
3. 중력 순서·42칸·동일 시드 동일 결과.
4. 잔향 최대8·ID 추적·다음 탭 발동/실패 만료·스킬 보존/회복전환·턴 경계 유지·재귀 방지.
5. 스킬 후보 부족/0, 1턴 사용→4턴 재사용, 빠른 입력 중복 방지.
6. 3탭 정산, 회복 상한, 보스 사망 후 반격 없음, 패배/재시작.
7. 과충전 발동 시점·배율·게이지 재축적 금지.
8. 모바일360px와 데스크톱에서 튜토리얼→전투→승패→재시작. 실제 브라우저 검증 불가 시 그 한계를 명시.
9. 인간 재미 검증은 별도: 두 번째 판에서 의도적으로 잔향을 만들 수 있는가, 더 큰 연쇄를 위해 다시 하고 싶은가. 자동 테스트 통과를 재미 입증으로 보지 않는다.

- 구현 후 목표 플레이 길이와 난이도를 실제 측정한다.

## 일반 유입 구조와 보존한 실패

정적 frozen몸체+shapeCCD 조합의 복원 다음 행동에서 비정상 대좌표가 생긴 사례는, 몸체를 월드에 넣기 전에 KINEMATICfreeze로 등록하는 수명주기 수정으로 다뤘다. 제품의 CCD2는 유지했다. 이는 관찰한 조합 현상이며 엔진 내부 원인을 확정하지 않는다.

이후 누적된 일곱 물리 실패를 모아 독립 아키텍처 검토를 진행했다. 두 x 후보·선호 역전 대기·순번에 따라 높아지는 생성 위치는 일반 해결로 수용하지 않았다. 현재 구조는 생존자의 실제 붕괴를 기다린 뒤 한 번 생성한 배치의 순서·속성을 유지한다. 각 새 기물 자체의 회전된 크기로 위쪽 생성 높이를 제한하고 실제 현재 형상의 전체 가로 폭에서 진입 가능 구간과 아래 방향 첫 접촉 경계를 구한다. 깊이·원래 x와 거리·낮은 x 순서로 선택하고 실제 위치의 간격을 다시 검사한다. 막히면 물리를 진행한 뒤 다시 읽는다.

한 프로세스 프레임에는 성공·막힘을 합쳐 한 번만 계산하며, 물리 따라잡기 호출도 이 한도를 공유한다. 배치 크기와 무관하게 연속 계산 횟수를 제한한다. 이전 프레임의 움직이는 기물 계산 결과를 재사용하지 않는다. 생존자 위치·속도 보정, 추가 난수·재추첨·배치 재정렬은 없다. 같은12초 물리 모의시간 한계, 정지28틱, CCD2, 최종42개·지지·범위·겹침 기준과 한 번 정산을 유지한다.

원래 위험/폭약사 전투3의23개 제거, 실제 재사용 시간 경로의 합법7, 원래21단계 약한 경로, 복원·연속 리필과 원래/파생 대합집합을 각각 보존했다. 고정한 옛 선행 단계와 새 유입을 시험한 대상 단계를 구분한다. 새 시점을 적용한 격리 원래 실패 묶음은 모두 통과했고, 이후 최신 통합 여섯 탐험도 통과했다. 과거 실패·진단 결함·종료 경고는 보존하며 새 성공으로 덮지 않는다.

이 구조는 생성 간격·높이·기물 보존과 호출 집중을 다룬다. 임의의 모든 합법 보드가12초 안에 성공적으로 쌓인다는 증명은 없다. 새로운 경로에서는 정상 오류가 남을 수 있다.

## 판단·비용과 다음 검증

[구현 중35개 판단과 잘못 판단했을 때의 비용](resonance-v2-rulings.md)을 원장 순서대로 기록했다. 승인된 구현·독립 검토 범위에서 작업했고 추가 유료 API·서버·구독·의존성을 만들지 않았다. 실제 계정 과금·토큰 사용량은 이 환경에서 측정하지 못했으므로 금액0이라고 단정하지 않는다.

후속 검증은 세 가지다.

1. 실제 휴대폰·터치 하드웨어와 프레임/입력 비용 프로파일링.
2. 사람의 정상 플레이로 재미·난도·기다림과 빈 공간을 평가.
3. 새 합법 물리 실패가 생기면 원래 시드·상태를 보존해 일반 구조로 분석.


최신 부모 지시에 따라 전체 영상 재제작은 필수로 요구하지 않는다. 기존9c 전체 영상은 해당 커밋·범위의 근거로 보존하고, 최신 표시 수정은 별도 짧은 UI 영상·원본 크기 프레임으로 제시한다. 새 지침이 도착하기 전에 진행 중이던 녹화는170/0/정상3승HP45로 끝났지만 재시작하지 않았으며 전체 원본은 비공개로 보존한다. 공개에는 필요한 새 UI 구간만 제공하고 이전 전체 영상을 최신 화면으로 부르지 않는다.

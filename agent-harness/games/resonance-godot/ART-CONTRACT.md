# 첫 캐릭터 아트 패키지 · 제작 전달 사양

2026-10-20. 귀여운 펜선·수채화 스타일의 한 캐릭터를 먼저 완성한다. 배경 크롭을 전경 캐릭터로 대체하지 않는다. 아래는 제작 요청 사양이며 자산 수령/검수가 완료됐다는 뜻이 아니다.

## 전투 전경

- 개별 RGBA 투명 PNG, **1024×1024**, sRGB. 흰 배경·바닥 그림자·문자·UI·배경 장식은 넣지 않는다.
- 모든 프레임 동일 카메라/시점/의상/무기/신체 비율. 전신 크기는 약 720~820px 높이, 주변에 최소64px 여백. 공격 무기도 잘리지 않게 한다.
- **공통 발 접점/피벗 (512, 900)**. 캐릭터를 임의로 가운데 정렬하거나 프레임마다 크롭하지 않는다. 떠 있는 캐릭터도 가상의 동일 발 기준점을 사용한다.
- 초기 권장 파일: `hero_idle_01.png`, `hero_idle_02.png`, `hero_attack_windup.png`, `hero_attack_strike.png`, `hero_attack_recover.png`, `hero_hurt.png`, `hero_victory.png`.
- 대기 두 장은 호흡/눈깜박임 수준. 공격은 준비→타격→복귀의 실루엣이 명확히 달라야 한다. 피격은 순간 움찔/표정 변화. 최종 영상으로 아직 검수하지 않았다.
- 엔진 쪽 시작 타이밍: 대기800~1200ms, 공격 준비120ms/발동80ms/복귀180ms, 피격140ms. 실제 그림을 넣고 조정한다. 파티클과 피격 플래시는 별도 Godot 레이어에서 처리하므로 원화에 넣지 않는다.

## 얼굴 초상

- RGBA PNG **512×512**. 기본·집중·피격 3종: `hero_portrait_neutral.png`, `hero_portrait_focus.png`, `hero_portrait_hurt.png`.
- 같은 얼굴·머리·소품·광원, 눈의 중심 높이 약220px. 머리 장식이 잘리지 않는 여백. UI 테두리·배경·이름은 넣지 않는다.

## 선택적 분리 레이어

프레임 대신 가벼운 본/레이어 애니메이션을 제작할 경우 모든 레이어를 동일1024×1024 캔버스에 정렬한다. back accessory → rear arm → torso/legs → head/hair → front arm/weapon → front accessory 순. 어깨/목/허리의 분리된 부분은 원본 좌표와 피벗 메타데이터를 함께 제공한다. 첫 버전에는 7장의 일관된 프레임이 우선이며, 분해된 몸을 억지로 조합하지 않는다.

## 효과 자산 인터페이스

연결 예고(지속) → 소거(약120ms) → 폭탄(약240ms) → 적 피격(약140ms) 순의 읽기 쉬운 타이밍을 우선한다. 연결·소거는 동일 속성색을 유지한다. 불꽃 분홍/주황, 별빛 금색, 물방울 하늘색, 회복 민트. 준비 중 장식보다 실제 선택 가능 상태를 우선한다.

Godot 네이티브 파티클/셰이더로 시작할 수 있다. 외부 무료 텍스처를 추가한다면 PNG RGBA 128×128 또는256×256, 흰색 마스크(틴트 가능), 가운데 정렬, 출처·작성자·라이선스 파일을 함께 보존한다. ‘무료 다운로드’만으로 재배포 가능한 자산으로 판단하지 않는다. 유료 자산·원작 자산은 사용하지 않는다. 현재 새 효과/캐릭터 자산은 아직 받지 않았다.

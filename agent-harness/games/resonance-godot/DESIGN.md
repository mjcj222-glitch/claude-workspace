# Godot 전투 하나 · 초기 구현 범위

사용자는 웹판의 부자연스러운 쌓임과 보이는 접촉/논리 연결 불일치를 직접 확인하고 Godot으로 다시 제작하도록 요청했다. 목적은 기능 개수가 아니라 전투 한 화면의 조작 신뢰성·화면 품질을 먼저 완성하는 것이다. 이 문서는 초기 설계이며 플레이 가능한 완성본이 아니다.

## 프로젝트 분리

`feat/resonance-godot`은 최신 main `e2ebeb9`에서 분기했다. 작업 경로는 `agent-harness/games/resonance-godot/`다. 웹판은 별도 `feat/resonance-circuit`/PR2에 그대로 보존한다. Godot 저장은 `user://resonance_godot_v1.json`의 별도 버전을 사용하며 웹 저장을 읽거나 덮어쓰지 않는다.

예정 구조: `scenes/battle.tscn`, `scripts/battle.gd`, `scripts/board.gd`, `scripts/piece.gd`, `scripts/piece_geometry.gd`, `scripts/combat_rules.gd`, `scripts/save_store.gd`, `assets/characters/`, `assets/effects/`, `tests/`, `evidence/`. 외부 런타임 플러그인·추가 엔진은 사용하지 않는다.

## 물리와 조작

42개 `RigidBody2D` 기물과 벽/바닥 `StaticBody2D`를 사용한다. 원·둥근 네모·별·잎은 공통 폴리곤 데이터에서 표시, `CollisionPolygon2D` solids 충돌체, 터치 영역을 만든다. 별의 오목 부분도 엔진의 convex decomposition을 사용한다. 다른 도형을 투명한 원 위에 그리는 웹 구조는 이식하지 않는다. 두께/그림자 때문에 외곽이 부풀어 보이지 않게 검수한다.

상태는 낙하/안정화 → 선택 가능 → 미리보기 → 정산 → 리필/안정화 또는 적 반격 → 승패다. 안정화 전에 입력하지 못하며 버튼에도 그 이유를 표시한다. 안정화는 속도·회전·지지와 일정 시간 유지 조건으로 확인한다. 시간 초과를 ‘정상 안정’이라고 처리하지 않는다.

안정화한 보드의 실제 transform과 폴리곤을 스냅샷으로 만든다. 연결은 해당 폴리곤의 접촉/최소 거리로 판정하고, 허용 오차는 작은 픽셀 수준으로 수치·화면을 함께 검증한다. 떨어진 조각을 억지로 연결하는 확대 반경을 사용하지 않는다. 미리보기와 확정은 같은 스냅샷·규칙 함수를 사용한다. 터치/마우스 누름은 미리보기, 같은 조각에서 떼면 확정, 드래그/취소는 무효. 키보드 선택/확정과 모션 감소도 지원 대상이다.

Godot 기본 물리의 기기 간/버전 간 결정론을 주장하지 않는다. 씨앗은 생성 순서에만 사용한다. 동일 저장 스냅샷의 연결·피해·스킬 계산 재현과 물리 안정성은 별도로 검사한다.

## 한 전투의 완결

기존 3탭 정산, 연쇄·잔향·속성 대형 폭탄과 세 스킬의 기본 의미를 가져오되 이번 범위에 새 난도·적 종류·유물·6층 탐험을 추가하지 않는다. 첫 전투의 적 하나, HP/반격 예고, 승리·패배·재시작을 완결한다. 큰 직접 연결은 생성할 특수와 실제 범위를 미리 알려 준다.

시간 제한 없이 선택 가능한 동안 스킬을 고를 수 있고 스킬은 탭을 쓰지 않는다. ‘사용 가능’은 실제 입력 허용과 대상 유무에 일치한다. 낙하 중/정산 중은 버튼을 잠그고 명시한다. 세 스킬이 같은 턴에 가능하다는 사실을 숨기지 않는다. 사용 직후 버프와 바뀐 기물을 보여 준다.

## 아트와 검수

기존 독자 수채 배경은 보존/재사용할 수 있다. 전경 전신·초상·대기/공격/피격은 `ART-CONTRACT.md`의 동일 캐릭터 세트로 교체한다. 임시 도형·기존 크롭·미수령 프레임을 최종 품질이라고 보고하지 않는다. 효과는 네이티브 파티클/셰이더를 우선하고 라이선스가 확인된 무료 자산만 검토한다.

검증은 각 도형 경계 터치, 붙음/떨어짐, 미리보기=제거, 안정화 후 지지/겹침/경계, 입력 잠금, 저장 스냅샷 정산, 승패/재시작을 포함한다. 실제 그래픽 실행이 가능해진 뒤 같은 화면에서 선택/낙하 영상을 촬영하고 부모의 참고 화면 비교 검수를 받는다. headless 물리 성공만으로 자연스러움·재미·최종 품질을 주장하지 않는다.

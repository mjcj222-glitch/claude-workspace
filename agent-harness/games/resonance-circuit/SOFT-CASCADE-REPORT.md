# 소거 중 설정 회귀 수정과 부드러운 타격 조정

2026-10-19. 규칙·캠페인·저장 스키마·패널/스킬·원본 아트는 변경하지 않았다.

## 변경

- 사운드 토글/미리듣기 토글은 `renderAudio()`만 호출한다. 안내 스킵은 `renderLesson()`으로 안내와 대상 강조만 갱신한다. 진행 중 `.cleared`, `data-clear-id`, 타일 내용과 애니메이션을 초기화하지 않는다. 설정은 즉시 저장/적용한다.
- BFS 28ms 순서와 큰 그룹 420ms 압축은 그대로다. 보석은 170ms 동안 .88 눌림 → 1.17 팝 → 수축·페이드. 밝기는 최대1.10으로 원색을 유지한다. 작은 광륜, 둥근 빛조각, 1px·최대알파.35·130ms 연결선으로 흐름을 보강했다. 조각 수는 기존3/5개에서2/4개로 줄였다.
- 낙하는 200ms ease-out, 마지막1px 착지 정착. 마지막 소거 후198ms에 정산/낙하 시작,220ms 뒤 입력 해제. 계획 총시간은6칸558ms,42칸838ms다. 브라우저 스케줄링 지연은 이 상한을 늘릴 수 있다.
- 큰 연쇄 끝에 작은 광륜과196/294Hz 저음 공명. 순차음은294–588Hz의65ms 사인파로 낮추고 게인 .045→.038. 카메라 흔들림/전체섬광/볼륨 증가는 없다.
- reduced-motion/설정의 효과 줄이기는 이동선·입자·팝·낙하를 생략하고 정적 강조만 사용한다.

## 한계

실제 청취나 사용자 체감 평가를 대신하지 않는다. 영상 프레임과 자동 테스트는 재미/타격감의 객관적 증명이 아니다. 관리형 브라우저의 file URL 제한은 변경하지 않았고 로컬 바이트를 Playwright 라우트로 제공해 검수했다. 외부 패키지/에셋 다운로드·배포·main 병합 없음. ZIP의 standalone.html을 압축 해제 후 열어 실행한다.

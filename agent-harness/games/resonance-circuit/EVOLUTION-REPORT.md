# 잔향 회로 — 속성 대형 폭탄과 부드러운 낙하

2026-10-20 UTC. 기준 `1e2e521`, 검토 브랜치 `feat/resonance-circuit`, [Draft PR #2](https://github.com/mjcj222-glitch/claude-workspace/pull/2). 실행 환경을 실제 확인한 뒤 같은 게임 폴더 안에서 후속 개발을 진행했다. 마무리 시 최신 main `e2ebeb9`의 작업 지침·README·topics·build 문서 및 Issue #1을 다시 확인했으며 해당 지침에는 변경이 없었다. Python 3.12.14, Node v24.19.0, 기존 Playwright와 Chromium을 사용했다. 하네스 check 및 Python 5개 검사는 종료 0이었다.

## 달라진 플레이

새 게임은 공격색 **8개 직접 연결**로 탭의 확정색을 가진 대형 폭탄 하나를 만든다. **5~7개는 차지**, 회복색은 회복만 한다. 무지개는 직접 연결 수에 포함하며 잔향·폭발로 추가 제거한 수는 생성 기준에 포함하지 않는다.

| 종류 | 범위 | 활용 |
|---|---|---|
| 소형 폭탄 | 현재 접촉 그래프의 한 겹 이웃 | 연쇄 점화 스킬로 만들고 가까운 덩굴을 연다 |
| 불꽃 대형 | 제거 전 접촉 그래프의 두 겹 이웃 | 밀집한 주변 기물을 넓게 제거한다 |
| 별빛 대형 | 가로 띠 | 떨어진 같은 높이의 기물·폭탄을 연결한다 |
| 물방울 대형 | 세로 띠 | 위아래로 떨어진 기물·폭탄을 연결한다 |

띠 판정은 폭탄과 대상의 중심 좌표 차이가 `폭탄 반지름 + 대상 반지름 × 0.5` 이하인 경우다. 실제 터치·충돌 원을 크게 만들지 않고, 원 안의 이중 테두리와 방향 문양·“대형” 표시로 구분한다. 미리보기는 실제 제거 집합을 강조하고 연결 수·생성될 특수·폭발 수를 표시한다. 소형/대형이 서로 맞으면 각각 한 번 발동하고 같은 ID의 피해·회복도 한 번만 계산한다.

새 폭탄은 기존 효과 정산 이후 새 ID로 생성되어 **다음 탭부터** 사용한다. 만든 탭의 폭탄 수·점화·씨앗 화약 계산에는 포함하지 않는다. 점화와 화약의 기존 최대 3개 상한도 유지했다. 덩굴은 맞아도 해제만 되며 같은 탭에 제거되지 않는다. 폭발만 기존 잔향에 닿을 때는 다른 표식을 발동시키지 않는다. 새 잔향의 같은 탭 재귀 발동도 없다. 프리즘 링크는 대형 폭탄의 속성을 바꾸지 않는다.

## 진행과 난도

지도 v2의 6개 방 구조를 유지했다. 첫 보드는 난수 재추첨 없이 정착 좌표의 접촉 그래프를 분석해 학습 기회를 배치한다. 30개 시드 × 3단계에서 직접 8개 연결→대형 생성→다음 탭 활용을 확인했다. 덩굴 단계에는 인접 소형 폭탄이 있으며, 무지개 단계에는 **분리된 같은 색 3개 + 무지개 1개 + 같은 색 4개**가 정확히 8개 연결이 된다. 이후 리필은 기존 난수 스트림을 사용한다.

| 층 | 경험 | 새 규칙의 적 체력 / 반격 |
|---|---|---|
| 1 | 대형 폭탄 만들기와 다음 탭 활용 | 360 / 10→16 |
| 2 | 덩굴 활용, 일반 또는 정예 선택 | 일반 560 / 12→18, 정예 680 / 20→30 |
| 3 | 휴식·상인에서 빌드 조합 | 회복 또는 체력 비용과 유물 |
| 4 | 무지개 연결·잔향 장막·필수 중간보스 | 920 / 16→24→32 |
| 5 | 체력과 유물을 보고 최종 준비 | 회복 또는 유물 보완 |
| 6 | 배운 조합과 3탭 정산의 종합 시험 | 1300 / 20→30→42, 잔향 장막 |

첫 보상은 긴빛 렌즈·잔향 방울·꽃잎 변압기 중 핵심 빌드를 제시한다. 다음 보상은 선택한 빌드의 보완 유물을 우선한다. 일반전은 2개, 정예·중간보스는 3개 중 하나를 고른다. 후보는 시드·보유 유물로 결정하며 재로드·중복 클릭으로 보상을 다시 뽑거나 두 번 받지 않는다.

초기 4개 시드 비교에서 폭딜 정책의 평균 완주가 기존 19.5턴에서 새 규칙 16.5턴으로 줄었다. 이에 첫 전투는 유지하고 이후 적의 체력·반격과 최종보스 장막을 조정했다. 최종 비교는 고정 시드, 일반전·휴식 경로, 즉시 피해·잔향·회복을 다르게 평가하는 세 정책과 스킬을 사용하지 않는 무작위 정책으로 실행했다. 정책은 최적 플레이나 사람을 대표하지 않는다. 첫 보드의 학습 보장이 포함되므로 전체 플레이가 순수 난수 실험인 것도 아니다.

## 낙하와 선택 장면

`flow.mjs`의 고정 timestep, 정착 좌표, 물리 반지름, RNG는 바꾸지 않았다. 렌더 전용 `flow-motion.mjs`가 구간 범위를 넘지 않는 단조 Hermite 곡선을 샘플링하고, 위치는 transform으로 재생한다. 마지막 투영 보정에 별도 정착 시간을 주고 끝 속도를 0으로 만든다. 마지막 좌표는 저장된 최종 좌표와 정확히 일치한다. 재생 시간 상한은 이전 850ms에서 720ms로 낮췄다.

24개 시드의 실제 144탭 계측에서 마지막 보정의 최대 이동은 13.44 월드단위였다. 5단위를 넘는 보정 8건은 약 77.6~95.5ms 구간에 연결했다. 해당 표본의 전체 낙하 재생은 약 469.9~642.7ms였다. 모든 최종 좌표·trace·게임 상태 불변과 경계·비겹침을 검사했다. 공유 개발 환경의 순수 정산 CPU 시간은 평균 약 202.5ms, 최대 약 789.5ms였다. 이는 모바일 성능 보증이 아니며 무거운 동기 계산이 사라졌다고 주장하지 않는다.

선택 장면은 기존 그림을 고정하고 등불·달무리의 낮은 밝기 변화, 2~3개 빛점의 6~8px 이동, 작은 잎 움직임을 사용한다. 보상은 문구·카드를 고정하고 유물 문양만 짧게 정착한다. scene key가 바뀔 때만 입장 효과를 시작한다. 장식은 `aria-hidden`·`pointer-events:none`이며 상태나 저장을 수정하지 않는다. 선택 버튼은 첫 프레임부터 활성이다. 시스템 또는 앱 모션 감소는 정적으로 표시하고 숨김·모달 닫기에서는 반복 효과를 멈춘다.

## 호환과 수정한 오류

새 게임만 독립 필드 `rulesVersion: 1`을 사용한다. 보드 버전 1과 지도 버전 1/2는 별개다. 기존 hex·좌표 보드 저장에는 새로운 폭탄, 유물 후보, 적 수치를 강제로 적용하지 않는다. 변경 전 좌표 저장 41개를 별도 golden fixture로 보존했고, 기존 hex 29개 corpus 및 기존 회귀 검사도 유지했다. `kind: mega`·색·ID·좌표는 두 저장 경로에서 보존하며 버전 위조와 회복색 대형 폭탄은 거부한다.

일반 모션으로 탐험을 완주하는 검사에서 장식 캔버스의 음수 반지름 오류를 발견했다. 지연된 RAF timestamp가 효과 생성 시각보다 앞설 때 음수 경과 시간이 생기는 문제였다. 실패 상황을 재현하는 검사를 먼저 실행한 뒤 경과 시간을 0 이상으로 제한했다. 물리 timestep이나 게임 정산에는 영향을 주지 않는 수정이다. 실패 로그 `evolution-expedition-first.log`, `evolution-effects-clock-red.log`를 보존했다.

## 실행·산출물·한계

`resonance-circuit.zip`을 풀고 `standalone.html`을 연다. 모듈판은 이 폴더에서 `python -m http.server 8000 --bind 127.0.0.1`로 실행할 수 있다. `package_game.py`는 현재 소스·내장 이미지·보고서·영상을 다시 묶는다. 핵심 변경 파일은 `mechanics.mjs`, `engine.mjs`, `campaign.mjs`, `expedition.mjs`, `storage.mjs`, `flow-motion.mjs`, `flow-ui.mjs`, `choice-motion.mjs`, `app.mjs`, `evolution.css`, `effects.mjs` 및 검사·문서·패키지다.

최신 실제 영상은 `evolution-play.mp4`다. 390×844, 60fps 컨테이너, 32.4초, 2,304,584바이트이며 실제 캡처 1,344장을 원래 시간 간격으로 인코딩했다. 시드 510115977의 정상 탐험 완주에서 대형 생성·다음 탭 폭발·낙하·유물·휴식·이벤트·결과를 담았다. 캡처 프레임 사이를 복제하는 인코딩이므로 실기기 60fps 성능 증거가 아니다. 기록한 장면은 원래 속도이며 반복 중간 탭은 모션 감소로 진행하고 영상에서 생략한다. 게임 프레임을 합성하거나 낙하를 가속하지 않는다. `evolution-attribute-*` 이미지는 유효 저장 fixture로 세 속성의 실제 미리보기 범위를 비교한 검사 화면이다. 전체 완주 증거와 구분한다.

실물 Android/iOS, Safari/Firefox, 스크린리더, OS 큰 글자, 실제 청취, 장시간 난도 및 사람의 재미 평가는 미검증이다. 관리 환경의 `file://` 직접 실행 제한은 변경하거나 재시도하지 않았고 동일 단일 HTML을 브라우저 응답 경로로 검사했다. 현재 구현·GitHub 게시 작업에는 환경 차단이 없었다. 자동 완주·승률을 재미나 상용 품질의 증명으로 보지 않는다.

외부 패키지·에셋 다운로드, 새 API 키, 유료 영상 생성, 결제, 보안 설정 변경, 파일 삭제, 수동 배포, main 병합은 하지 않았다. 원화와 그림체는 기존 독자 자산을 유지했다. 이전 산출물은 저장소에 보존하고 최신 패키지만 갱신했다.

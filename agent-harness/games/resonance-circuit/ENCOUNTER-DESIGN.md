# 큰 얼굴 도크와 탐험 장면 설계

2026-10-20. 기준 커밋 `2a8923a`, 구현 체크포인트 `6ba379f`. 요청은 귀여운 얼굴 확대, 잡몹·중간보스·최종보스·휴식·이벤트의 구분, 무대와 HUD·보드·스킬 도크의 통합이다. 기능 검사 통과를 시각 품질이나 재미의 증명으로 해석하지 않는다.

새 탐험(version 2)은 잡몹 → 잡몹/정예 → 휴식/이벤트 → 필수 중간보스 → 휴식/이벤트 → 최종보스 순서다. 4층 황동 사슴은 HP 780, 장막 20%, 반격 14→22→26이며 승리 시 체력 12와 유물 선택 한 번을 준다. 첫 반격은 무지개 도입과 겹치는 부담을 줄이도록 낮췄다. 6층 일식 화룡은 HP 1000, 반격 16→24→34이며 처치하면 탐험이 끝난다.

저장키 `resonance-expedition-v1`을 유지하고 내부 버전 1·2를 모두 검증한다. v1은 기존 지도·경로·RNG·보상·전투 수치를 보존한다. 기존 저장에 중간보스를 강제로 삽입하지 않는다. v1의 4층 전투에는 중간보스 장면만 적용하며 규칙은 그대로다. 변경 전 생성한 v1 고정 저장 9개와 패배·중복 보상·버전 위조 사례로 호환성을 검사한다.

`encounters.mjs`는 장면 분류와 이름, `encounter-ui.mjs`는 화면 표시를 담당한다. 보스 진입 이름은 0.65초 동안 나타나며 입력을 잠그거나 화면을 번쩍이지 않는다. 축소 모션에서는 정적인 이름을 사용한다. 숨김·새 게임·모드 변경 시 남은 표시를 정리한다. 선택 연결선은 최초 연결 그룹의 인접 관계만 표시하고 게임 상태와 RNG를 변경하지 않는다.

원본 2:1 무대의 주요 실루엣을 보존하고 가장자리를 먹색 프레임에 부드럽게 연결한다. 적 체력·다음 반격·플레이어 체력·남은 탭의 순서가 이어지도록 구성했다. 얼굴 슬롯은 64px, 360×640 화면에서는 60px다. 각 724×724 초상 중앙 517.14×517.14를 사용해 눈·코·입을 1.4배 확대한다. 보드 타일은 최소 40px 높이다. 휴식·이벤트·보상에서는 전체 지도를 숨기며 지도 화면에서는 전체 경로와 노드 상세 진입을 유지한다.

수신한 오리지널 아트는 귀여운 3인 초상과 잡몹·중간보스·최종보스·휴식·이벤트 6장이다. 정예에는 기존 오리지널 가면여우 그림을 사용한다. 원본 PNG를 보존하고 픽셀이 같은 lossless WebP를 표시용으로 사용한다. 독립 HTML에는 각 이미지를 한 번만 내장하고 짧은 Blob URL로 공유한다. 실제 검수와 한계는 [ENCOUNTER-REPORT.md](ENCOUNTER-REPORT.md)에 기록한다.

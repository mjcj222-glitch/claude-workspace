# 모바일 게임 프레임 설계

고정100dvh+safe-area 프레임. 상단은 상태/메뉴 아이콘, 그 아래 전체 비율을 유지한 적 무대와 HP/다음 행동, 플레이어 HP·남은 탭,42칸 보드,항상 보이는3인 스킬 도크/과충전. 제목·외부 카드 여백·하단 보조버튼 나열 제거. 상세 피해/잔향/로그/설정/규칙은 메뉴 오버레이로 이동. 튜토리얼은 보드 위 작은 안내 풍선으로 제공하며 스킵 가능.

360px 타일 높이40px,390px 이상44px 유지. 도크는 작은 캐릭터초상+스킬명+준비표시. 짧은640px에서도 게임영역 스크롤 금지. 적 무대 높이는 유연하게 줄이되 이미지 비율/전신은 보존한다. 오버레이 내부는 긴 내용 스크롤 허용. 키보드 포커스와 닫기/이전 화면 복귀 제공.

지도는6층 노드/연결선 중심, 위험/보상은 노드 탭→상세→진입. 노드 탐색만으로 게임상태/저장/RNG 변경 없음. 전투 중 메뉴열림은 추가 탭을 차단하고 이미 진행 중 해소는1회 완료하며 소거 클래스는 보존한다.

검증:360×640/800,390×844,1280×900×일반/축소. 전투 영역 세로/가로 넘침0,모든타일/스킬/과충전 viewport내,적비율,오버레이반복/키보드/중복탭/탐험경로진입,기존108개와 완주. 실제스크린샷/영상,독립HTML/ZIP,CI는 조회결과를 별도로 보고.

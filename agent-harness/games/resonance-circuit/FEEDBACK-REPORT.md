## 오디오 구조와 제한

Web Audio 사인 기본음과 부드러운 배음,9ms 어택/짧은 감쇠, 캐시한 필터 노이즈만 사용한다. 사각파·배경음악·외부 음원은 없다. 기존 기본 무음·사용자 제스처·전체 음량·숨김 정지·오디오 실패 시 게임 독립을 유지했다.

- 마스터 게인과 compressor(threshold -16dB, knee18, ratio5:1, attack3ms, release120ms)를 공통으로 사용한다. 음량 변경은 진행 중/예약된 소리에도 적용한다.
- resume 완료 전 소리는 최대4개/250ms 대기열에서 기다린다. 숨김/음소거는 대기열 세대를 폐기하여 오래된 소리를 복귀 재생하지 않는다.
- 이벤트 ID 중복 제거는 최근64개, 같은 이벤트 최소45ms 간격. 동시 소스 최대8개, 소스별 gain/filter 포함 보수적 노드 상한26개. 혼잡 시 초과 음표를 생략하므로 극단적 복합 상황에서 모든 배음이 재생되지는 않는다.
- 노이즈 버퍼는 한 개, 최대48kHz×.35초×float32 = 67,200바이트. 96kHz 장치에서도 이 상한을 유지하며 브라우저가 리샘플링한다.
- 음소거/숨김 시 짧은 마스터 게인 감쇠를 예약하고 소스를 정지한다. 숨김 suspend는 즉시 요청하고35ms 안에 잔여 노드를 정리한다. 클릭 잡음 감소를 의도했지만 실제 청취로 확인한 것은 아니다.
- 시각 입자80개, 떠 있는 글자3개 상한. 표식은 고정 UI 대상에만160ms 유지하며 clear에서 타이머까지 정리한다. 전체 JS heap 또는 실물 기기 FPS를 보장하는 측정은 아니다.

## 발견·수정한 실패

신규 오디오 검사 초기에는 telemetry·대기열 미구현으로 실패했다(`feedback-before.log`). 구현 과정에서 기존 숨김 즉시 suspend 계약과 테스트 mock의 예약 stop 시점을 맞췄다. WAV 검사에서 최초 마스터 게인 예약 취소가 초기값으로 되돌아가 음량0에 짧은 신호가 생기는 문제를 발견했다(`feedback-audio.log`, 종료1). 현재값을 보존한 뒤 게인을 변경하도록 고쳐 최종 무음0을 확인했다(`feedback-audio-final.log`, 종료0). 96kHz 캐시가 상한을 넘는 실패도 먼저 확인하고48kHz 제한으로 고쳤다(`feedback-buffer-before.log`).

첫 FX 검사는 emulate_media 반환 직후 change 이벤트보다 먼저 입자0을 단정해 실패했다(`feedback-browser-initial.log`). 실제 모션 변경 이벤트 적용을 기다리도록 검사기를 고친 뒤6조합 통과했다. 단순히 대기 시간을 길게 주어 효과가 자연 만료된 것을 성공으로 보지 않고 fx-reduced 상태와 즉시 clear 상태를 함께 검사한다.

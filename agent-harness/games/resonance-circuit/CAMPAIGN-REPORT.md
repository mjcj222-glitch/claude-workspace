# 세 정원 탐험 완성도 확장 보고

## 완료된 한 판

시작/이어하기 → 실제 보드 위 큰 묶음·ID 기반 잔향 안내 → 새싹 회랑 → 2택1 성장 → 수정 정원 → 2택1 성장 → 예고 패턴 최종 보스 → 전투별 결과 → 새 탐험/체크포인트 재도전으로 연결했다. 캐릭터 재디자인 없이 기존 승인 시안의 원본과 sprite를 유지했다.

성장은 공격+1 또는 최대체력+50, 이어서 차지 추가피해+20 또는 회복+3이다. 선택은 전투별 한 번만 가능하다. 전투 승리 후 체력45 회복(최대치 제한), 게이지 유지, 새 보드·빈 잔향·빈 대기 피해·과충전 해제·준비된 스킬·1턴3탭으로 전환한다. 패배 재도전은 진입 HP/게이지/성장/시드로 보드와 RNG를 정확히 재구성하며 숨은 보정을 하지 않는다. 최종 결과에 전투별 턴·잔향·재도전 수, 성장 선택, 최대 연쇄를 표시한다.

튜토리얼은 실제 큰 묶음을 강조하고 다음 단계의 잔향 타일 ID를 추적한다. 다른 타일을 눌러도 막지 않으며 언제든 건너뛸 수 있다. 완료/건너뛰기는 저장되어 다음 탐험에서 반복하지 않는다. 규칙 팝업은 별도로 유지했다.

## 코드와 저장

- `engine.mjs`: 기존 25개 검사를 유지하며 전투별 rules를 받도록 확장. 기본 단일 전투 호출의 의미는 유지.
- `campaign.mjs`: 세 전투, 예고, 성장, ID 학습 안내, 전투 재도전.
- `storage.mjs`: 버전1 저장. ID 중복/범위/상태/단계/선택/보드/게이지/체력/시드/오디오 설정을 검증하고 규칙 수치는 다시 계산. 손상 데이터는 이어하기에 쓰지 않음.
- `audio.mjs`: 기본 꺼짐, 사용자 제스처 후 AudioContext 시작, 음량, 최대8음 제한, 탭 숨김 시 중단, 실패 시 게임 독립.
- `app.mjs`: 시작/성장/결과/새게임 확인 UI. 매 확정 상태를 저장하며 저장이 막혀도 플레이 가능.

음향은 사인/삼각파와 짧은 완만한 엔벌로프의 타격, 상승 음정, 낮은 폭발을 사용했다. 실제 청취 검수는 불가능하여 소리 품질을 보증하지 않는다. 헤드리스 브라우저에서 실제 AudioContext의 사용자 토글 후 running, 제어된 visibilitychange 후 suspended 상태와 실패 처리를 확인했다.

효과 문구는 타일마다 띄우지 않고 HUD 안내로 줄였다. 실제 폭탄/잔향/보스 HP 감소/적 반격만 해당 피드백에 연결했다. 입자 생성은 탭당 최대12타일에 제한하고 기존 총100개 상한을 유지했다. 초상을 정사각 카드로 확대해 하단 원소 배지가 보이게 하고 타일 간격·설명 글자·음향 버튼 대비를 조정했다.

## 밸런스 실험

10개 고정 시드(20261019, 1, 7, 42, 99, 314, 777, 12345, 98765, 4294967295), 전략 3종을 실제 실행했다. 기본 성장 선택은 공격/회복이다. 아래는 자동 전략 결과이며 사람의 재미·플레이 시간 검증은 아니다.

| 전략 | 3전투 완주 | 1전투 턴 | 2전투 턴 | 3전투 턴 |
|---|---:|---:|---:|---:|
| 스킬·과충전·피해/회복 평가 | 10/10 | 4–6 | 4–7 | 7–10 |
| 최대 묶음만 선택 · 스킬 없음 | 10/10 | 5–7 | 7–10 | 11–16 |
| 최소 묶음만 선택 | 0/10 | 12–22 | 도달 못함 | 도달 못함 |

네 성장 조합도 각각10시드로 검사했다. 공격/차지 10/10(전체17–20턴), 공격/회복 10/10(18–20턴), 체력/차지 10/10(19–23턴), 체력/회복 10/10(20–24턴) 완주. 능숙한 자동 전략에는 여유로운 난이도이며 성장 선택 간 사람의 선호·균형은 미검증이다.

검토자가 제안한 낮은 후보 적 체력180/360/760과 반격 패턴도 별도 프로세스에서 시험했다. 전략형의 첫 두 전투가1–2턴에 끝나 학습 기회가 짧았다. 최종 후보는620/1100/1700과 반격14→20, 20→30, 18→26→40을 채택했다. 무작위 공격이나 즉사는 없다. 데이터는 campaign-balance.jsonl, campaign-choice-balance.jsonl, campaign-candidate-balance.jsonl에 있다.

## 남은 한계

실물 모바일·Safari/Firefox·스크린리더·실제 터치 스크롤, 실제 오디오 청취, 사람의 재미와 소요 시간은 미검증이다. file://는 이전 관리 정책 차단으로 재시도하지 않았고, 브라우저 내부 route 실행을 직접 파일 열기 성공으로 표현하지 않는다. 저장은 브라우저/주소별이며 기기 동기화가 없다. 브라우저 데이터 삭제 시 복원할 서버도 없다.

모든 변경은 게임 폴더 안이다. main 병합·수동 배포·Vercel 설정 변경·추가 결제·API 키·패키지 설치·권한 확대는 하지 않았다. 같은 Draft PR #2로 제안하며, 무결점/상용급 완성/재미 입증으로 과장하지 않는다.

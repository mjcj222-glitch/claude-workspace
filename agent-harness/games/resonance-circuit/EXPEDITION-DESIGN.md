# 탐험 v1 설계·완료 기준 (구현 전)

기존 연습3전투/저장키는 보존한다. 탐험은 별도 `resonance-expedition-v1` 슬롯, version1. 시작 선택/모드 전환은 현재 슬롯을 저장하고 다른 슬롯을 덮어쓰지 않는다. 새 탐험은 확인 후만 대체한다. 죽음/완주도 저장하며 전투 재도전은 없다.

6층, 실제6방 경로: 시작 일반전 → 일반/정예 → 휴식/이벤트 → 일반/정예 → 휴식/이벤트 → 최종보스1개. 각 층의 한 방만 선택하며 이전층/미선택 형제로 되돌아갈 수 없다. 지도에서 전투와 분리해 HP/위험/예고/보상/선택 경로를 표시한다. 방 시드와 유물 후보 순서는 시작 시 seed로 생성·저장한다. 조회/preview는 RNG를 소모하지 않는다.

HP180 유지. 보스HP는 순서360, 일반500/650·정예600/780, 최종1000. 예고 피해 일반10/16,정예18/26,최종16/24/34. 기존 깊이별 덩굴/무지개 안내 사용. 전투마다 스킬/보드 초기화, HP·게이지·유물 유지. 일반승리 HP+6,정예+12,보스 종료. 전투보상 미소유 유물2개 중1개; 하나남으면1개, 고갈하면HP+18 대체. 휴식HP+36. 이벤트는HP18지불하고 표시된 미소유 유물1개 또는HP+22. 지불 후HP1 이상 필요. 고갈시 이벤트도회복22. 모든 회복은180상한.

유물8종(중복획득 불가):
- 잔향 방울: 실제 잔향 발동 탭 보호6. 유물보호 최대12, 다음 반격 때 소진.
- 씨앗 화약: 실제 소거 기존 폭탄당 턴정산 회복3, 탭당최대9.
- 무지개 병: 최초 연결 무지개가 있으면 게이지5, 탭1회. 과충전 중은 생성하지 않음.
- 덩굴 찻잎: 실제 덩굴해제당 턴정산 회복2, 탭당최대6.
- 긴빛 렌즈: 최초 연결8개 이상이면 고정피해16, 탭1회.
- 꽃잎 변압기: 회복색 최초 연결4개 이상이면 고정피해12, 탭1회.
- 첫빛 브로치: 방의 첫턴 첫 성공스킬만 보호6, 방1회.
- 반달 우산: 체력90 이하로 턴의 마지막 탭을 시작하면 보호6, 턴1회.

순서: 실제 preview의 원본 타일/기존 표식/폭탄/해제 결과 → 유물효과 계산1회 → 고정피해/정산회복 적립·유물보호 누적 → 엔진 tap1회 → 실제 반격 후 보호 소진 → 보상/종료. 유물생성효과는 트리거 입력에 재투입하지 않는다. 피해보너스는 과충전 배율 제외, 장막은 최종합계 적용. 유물보호12+스킬18=총30상한. 유물은보드/표식/폭탄을 생성하지 않음. 턴정산 회복은 반격 전이며 즉시 부활 없음. 전투종료시 미사용보호 만료.

# 보석·카드 시안 충실도 후속 개선

## 구현

승인 원본 PNG의 첫 보석 행을 CSS sprite로 사용했다. 빨강 불꽃, 파랑 물방울, 노랑 별, 초록 잎의 면 분할·두께·반사광을 각 타일에 표시한다. 실제 버튼은 여전히 42개이며 DOM/게임 규칙은 유지된다. 전체 화면/보드 이미지를 클릭판으로 쓰지 않는다. 보석의 표시 비율은 약42×40px(360px), 46×44px(390px 이상)이며 타일의 독립 터치 영역은 약51.7×40px와56.7×44px다. 가로로 납작했던 모양을 줄였고 sprite 모서리의 원본 배경은 다각형으로 잘라냈다.

초상 표시 높이를 55–60px에서 88px로 늘리고 얼굴·상체·카드 일부가 보이게 했다. 화면 설명은 카드 이름으로 줄이고, 스킬 상세 의미는 버튼 aria-label과 튜토리얼에 유지한다. 비활성 과충전 버튼은 금빛 그라데이션과 테두리를 유지하며, 활성 시 밝은 외곽선·발광으로 구분한다. 실제 disabled 동작은 유지된다.

캐릭터는 변경하거나 재디자인하지 않았다. 원본 PNG와 manifest, 캐릭터 교체 슬롯을 보존했다. 보스 창 높이를 줄여 카드와 보석에 공간을 배분했다. 첫 수정 후 360px에서 버튼 하단이807px로 실패했고, 최종797px로 조정했다. 390px에서834px, 1280px에서850px다.

## 직접 비교

승인 원본과 새 `concept-ui-390.png`를 실제로 열어 연속 비교했다. 이제 보석의 불/물방울/별/잎과 유색 면·반사광, 세 캐릭터 카드, 금빛 버튼이 승인 시안의 핵심 인상을 공유한다.

차이는 남아 있다. 실제 게임은 시안보다 한 행 많은 7행이고 홀수 열이 내려간 hex 인접 구조다. 실동작 HUD·잔향 안내 때문에 시안보다 정보 밀도가 높다. 보스는 시안의 큰 전신 대신 상체 위주 창이며, 카드는 원본보다 작고 온실 배경은 보스 영역 밖에서 단순화했다. 선택은 원본의 거대한 연결광보다 절제된 빛과 키보드 포커스를 사용한다. 이번 결과를 상용급 완성 또는 완전 일치로 주장하지 않는다.

## 한계

file://는 이전 관리 정책 차단으로 재시도하지 않았다. 실물 모바일·Safari/Firefox·스크린리더, 실제 터치 스크롤/pointercancel, 사람의 재미·가독성 평가는 남았다. 규칙 엔진·효과·입력 잠금은 보존했다. 기존 PR만 갱신하며 main 병합·수동 배포·추가 서비스·새 패키지 설치는 하지 않는다.

# 모바일 게임형 화면 구조 개선

2026-10-19 · 기준 head6e9c878d · 게임 폴더 한정.

## 변경 결과

화면을 100dvh 고정 모바일 프레임으로 바꿨다. 상단 진행/턴/메뉴, 적 전신 무대·HP·행동 예고, 플레이어HP/남은탭,42칸보드,항상 보이는3인 스킬도크·과충전을 연결한다. 웹페이지 제목/카드 여백/하단 보조버튼 나열을 없앴다. 설명·상세 적립/잔향/상태/설정/재시작/모드 선택은 메뉴 오버레이로 옮겼다. 튜토리얼은 짧은 안내 풍선이며 상세 규칙은 메뉴에서 읽는다.

safe-area inset과 viewport-fit=cover를 적용했다. 큰 화면에서는430px 게임 프레임, 작은 화면에서도 게임 본문 스크롤 없이 조작한다. 긴 도움말/설정/결과만 dialog 내부 스크롤을 허용한다. 메뉴는 소거 중에도 열리며 추가 타일/스킬 입력을 차단하고 이미 진행한 행동은1회 정산한다. 닫기/Escape는 메뉴 아이콘으로 포커스를 반환한다.

지도는6층 노드와 점선 경로로 줄였다. 노드→위험/보상 상세→명시적 진입의2단계로 선택한다. 상세만 열고 닫으면 상태/저장/RNG는 변하지 않는다. 중복 진입은 기존phase 검사로 차단한다. 유물/이벤트 보상은 기존 선택 화면을 유지한다.

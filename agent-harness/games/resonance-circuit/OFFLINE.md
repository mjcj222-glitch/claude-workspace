# 잔향 회로 · 오프라인 실행

ZIP을 풀고 `standalone.html`을 브라우저로 여세요. 프로그램·이미지가 한 파일에 내장되어 있으며 인터넷이나 설치가 필요하지 않습니다. 이 개발 환경은 file://를 차단하므로 직접 파일 열기 성공은 미확인입니다. 동일 파일의 전체 플레이는 서버를 열지 않고 브라우저 내부 응답 방식으로 검사했습니다. 모듈판의 로컬 실행 명령은 [README.md](README.md)에 있습니다.

시작에서 6개 방 탐험 또는 3전투 연습을 선택합니다. 새 탐험의 4층은 중간보스 황동 사슴, 6층은 최종보스 일식 화룡입니다. 잡몹·정예·휴식·상인도 서로 다른 장면을 사용합니다. 탐험 패배에는 전투 재도전이 없으며 연습에서는 현재 전투를 다시 도전할 수 있습니다.

타일을 누르면 미리보기, 같은 위치에서 떼면 확정합니다. 드래그하면 취소합니다. 방향키·Enter/Space·Tab도 지원합니다. 첫 보드 안내에서 연쇄·잔향을 익힐 수 있고 메뉴에서 규칙·스킬 설명을 다시 엽니다. 3탭마다 회복·피해·예고 반격을 정산합니다. 스킬은 탭을 쓰지 않고 3턴 뒤 다시 준비됩니다.

소리는 기본 꺼짐이며 직접 켜고 음량을 조절합니다. 시스템 모션 줄이기와 실행 중 효과 줄이기를 지원합니다. `sound-check.html`과 `samples/*.wav`에는 합성음 확인 자료가 있습니다. 실제 청취·재미 평가는 하지 않았습니다.

이어하기는 같은 브라우저·주소의 localStorage를 사용합니다. v1 탐험 저장의 지도·수치·보상·RNG를 보존합니다. 저장 불가 상태에서는 창을 닫은 뒤 복구되지 않습니다. 새 게임은 덮어쓰기 전에 확인합니다.

최신 실제 녹화는 `encounter-play.mp4`입니다. 원래 속도로 캡처한 무음 장면을 이어 붙였으며 반복되는 중간 탭은 생략했습니다. 합성·조작한 게임 프레임은 없습니다. [ENCOUNTER-REPORT.md](ENCOUNTER-REPORT.md)에 검사·출처·한계를 기록했습니다. ZIP에는 현재 실행 구성만 담았고 원본 PNG와 과거 결과는 저장소에 보존합니다.

실물 모바일·Safari/Firefox·스크린리더·OS 큰 글자·320px 화면은 미검증입니다. 최소 검수 크기는 360×640이며 짧은 화면의 타일 높이는 40px입니다. [Draft PR #2](https://github.com/mjcj222-glitch/claude-workspace/pull/2)는 검토용이며 main 자동 병합·수동 배포·유료 사용은 하지 않았습니다.

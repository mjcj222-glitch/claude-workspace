# 잔향 회로 · 오프라인 탐험판

ZIP을 풀고 standalone.html을 브라우저로 여세요. 3전투와 두 번의 성장 선택, 최종 결과와 재도전까지 연결됩니다. 이미지와 프로그램은 독립 HTML에 내장돼 있습니다. 원본 모듈과 assets도 함께 제공합니다.

같은 모양·색을 누르고 떼면 해소, 드래그하면 취소합니다. 방향키/Enter/Space도 지원합니다. 5개 이상 연결하면 ◌ 잔향이 남고, 다음 연결이 표식에 닿으면 이전 잔향 전체가 발동합니다. 3탭마다 회복·피해·예고 공격을 정산합니다. 스킬은 탭을 쓰지 않고 3턴 뒤 다시 준비됩니다.

시작 화면의 이어하기는 같은 브라우저·주소의 버전 검증된 localStorage 저장을 사용합니다. 저장 불가 상태에서는 현재 플레이는 가능하지만 종료 후 진행을 복원할 수 없습니다. 새 탐험은 확인 후 진행을 덮어씁니다. 패배 재도전은 전투 진입 상태를 정확히 복원합니다.

음향 기본 꺼짐. 직접 켜고 음량을 조절할 수 있습니다. 외부 음원 없이 Web Audio로 생성하며 탭이 숨겨지면 정지합니다. 오디오 미지원이어도 플레이합니다. 기본 무음/reduced-motion/색 외 모양 구분을 지원합니다.

검증 한계: 개발 환경의 관리형 Chromium이 file://를 차단했으므로 직접 파일 열기 성공은 미확인입니다. 서버 없이 브라우저 내부 응답 방식으로 독립 HTML의 전체 흐름은 검사했습니다. 실물 모바일, Safari/Firefox, 스크린리더, 실제 청취·재미 평가는 남았습니다.

고유 스킬: 프리즘 링크는 다음 공격색 탭에 +12(잔향이면 +24), 연쇄 점화는 다음 실제 폭탄 해소 탭에 폭탄당 +10(최대 +30), 생명의 온실은 다음 적 반격을18까지 흡수합니다. 기존 타일 전환 기능도 유지합니다. 상단 스킬 설명에서 현재 대상 수와 쿨다운을 확인하세요. 준비 효과는 저장되며 중첩되지 않습니다. 두 번째 정원의 장막20%는 잔향 적중 시 현재 턴 해제됩니다. 이전 버전1 저장은 진행을 보존하며 새 효과는 다음 스킬 사용부터 적용합니다.

새 패널: 2전투부터 덩굴, 3전투부터 무지개가 등장합니다. 덩굴 직접 탭은 무효이며 이웃 소거/폭탄으로 껍질만 해제하고 다음 행동부터 연결됩니다. 무지개는 한 색만 연결하며 직접 누르면 최대 연결색(동률: 불꽃·별빛·물방울·회복)을 고릅니다. 미리보기에서 확정색을 확인하세요. 처음에는 실제 보드 안내가 나오고, 규칙 보기에서 다시 읽을 수 있습니다. 이전 저장의 현재 전투/재도전은 기존 배치를 유지하고 다음 전투부터 새 패널을 적용합니다.

전투 그림은 원본 비율로 크게 표시하며 안내 중에도 줄어들지 않습니다. 하단 스킬/설정은 세로 스크롤로 접근하세요. 시작/이어하기/새 전투는 그림부터 보이며, 일반 타일 입력 후에는 자동으로 화면을 위아래로 이동하지 않습니다.

연출·소리 버튼에서17개 효과음을 미리 듣거나 효과 줄이기를 선택할 수 있습니다. 시스템 모션 줄이기는 항상 적용합니다. 소리는 기본 꺼짐이며 전체 음량이 재생 중인 소리에도 적용됩니다. 독립 sound-check.html과 samples/*.wav로 소리를 확인하고, feedback-play.mp4에서 실제 무음 플레이 녹화를 볼 수 있습니다. 실제 청취 평가는 하지 않았습니다.

순차 소거: 탭 위치부터 hex 연결 순서로 압축·팝·수축한 뒤 낙하합니다. 큰 묶음은 마지막 시작420ms로 제한합니다. cascade-play.mp4는 실제 무음 플레이 영상, samples/cascade-6.wav·cascade-10.wav·cascade-42.wav는 순차 유리음 샘플입니다. 소거 중 새게임 요청은 적용 전 행동을 취소하고 확인창을 띄우며, 숨김/모션 변경은 행동을 한 번만 정산하고 연출을 정리합니다.

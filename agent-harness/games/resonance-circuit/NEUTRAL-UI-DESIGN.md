# 중립색 UI 시각 설계

문제: 청록 바탕·글로우·겹친 테두리가 화면 전체를 지배한다. 같은 강조 강도의 패널이 많아 캐릭터/보석/주요 버튼 계층이 약하다. 작은 보조 글씨와 초록 모달이 긴 지도/보상 화면의 가독성을 떨어뜨린다.

방향: 따뜻한 아이보리 배경(#f3f0e9), 밝은 카드(#fffcf6), 차콜 본문(#292930), 회색 보조문장. 라벤더는 주요 행동·선택·포커스에 제한한다. 회복/위험/블록 의미색은 유지한다. 어두운 차콜 퍼즐판은 색 보석과 옅은 입자 대비를 위한 전용 영역이다. 캐릭터 PNG는 수정하지 않는다.

전투 HUD/스킬/설정/시작·도움말·결과·지도·보상에 같은 토큰을 사용한다. 굵은 청록/금색 프레임·글로우를 없애고 얇은 구분선/여백/중량으로 계층을 만든다. 선택 경로는 체크표시+라벤더 면, 미선택 경로는 대시와 회색, 잠금은 명확한 본문 대비를 유지한다. 작은 화면의 긴 콘텐츠는 세로 스크롤을 허용하며 버튼과 글씨를 무리하게 축소하지 않는다.

검수: 같은 상태의 이전/이후 실제 스크린샷,360/390/1280×일반/축소, 시작/전투/지도/보상/방/결과/설정/설명, 키보드포커스·텍스트대비·가로넘침·버튼크기·소거효과. 전체 단위/harness 및 기존 연습/탐험 브라우저 회귀. 규칙·상태·저장·캐릭터·모션 타이밍은 변경하지 않는다.

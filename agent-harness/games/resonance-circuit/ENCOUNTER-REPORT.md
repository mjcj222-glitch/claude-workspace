## 구현과 실제 그림

귀여운 만화형 펜선·수채화 초상으로 교체하고 얼굴을 확대했다. 슬롯은 64px, 360×640에서는 60px다. 원본의 각 724×724 패널에서 중앙 517.14×517.14를 사용해 1.4배 확대한다. CSS 배경 크기 420% 140%, 가로 위치 6.25%·50%·93.75%, 세로 위치 50%로 인접 인물이 섞이지 않는다. 원본 PNG를 보존하며 그림 자체를 다시 그리지 않았다.

잡몹 등불나방·정예 가면여우·중간보스 황동 사슴·최종보스 일식 화룡·여우 상인·달빛 쉼터를 서로 다른 그림으로 연결했다. 원본 2:1 장면의 주요 실루엣을 유지하고 가장자리를 먹색 배경에 이어 무대와 HUD의 분리를 줄였다. 지도 상세에서도 해당 그림을 미리 보여 준다. 휴식·이벤트·보상에서는 전체 지도를 숨기고 선택에 집중한다. 상인 그림에 맞춰 사건 서술을 바꿨으며 통화·상점 규칙을 추가하지 않았다.

내 체력바·적 체력·다음 반격·남은 탭·보드·얼굴 도크를 한 프레임으로 연결했다. 과충전은 좁은 측면 조작부와 게이지로 정리했다. 색 외 4개 문양을 유지하고 대비를 높였다. 최초 선택 그룹만 정적인 인접 연결선으로 표시한다. 연결선 계산은 상태와 RNG를 바꾸지 않는다. 보스 이름은 0.65초간 나타나며 입력 잠금·플래시는 없다. 축소 모션에서는 정적 이름과 숫자를 사용하며 숨김·재시작·모드 변경 시 표시를 정리한다.

새 탐험 v2는 4층 필수 중간보스, 6층 최종보스다. 중간보스는 HP 780·장막 20%·반격 14→22→26·승리 회복 12와 유물 선택 한 번을 준다. 무지개 도입과 겹치는 첫 반격을 완충했다. 최종보스는 HP 1000·반격 16→24→34이며 처치하면 완주한다. 중간보스 처치는 탐험을 종료하지 않는다.

저장키를 유지하고 v1 저장의 지도·경로·RNG·전투 수치·보상을 그대로 복구한다. v1의 4층 기존 전투에는 중간보스 그림만 적용하며 규칙은 바꾸지 않는다. 변경 전 고정 저장 9개와 패배 저장을 검사했다. 새 맵은 v2에만 적용하며 버전별 결정론 지도 검증과 보상 중복 방지를 유지한다. 기존 `engine.mjs`, `campaign.mjs`, `storage.mjs`, `audio.mjs`, `timeline.mjs`는 이번 변경에서 수정하지 않았다.

## 패키지·영상과 실패 처리

원본 PNG 6장을 실제 수신하고 픽셀을 확인했다. 정예용 기존 그림과 함께 표시 이미지를 lossless WebP로 인코딩했다. 원본 PNG와 디코딩한 모든 RGB 픽셀의 일치를 검사했다. 시각 내용 수정이나 손실 압축은 없다. 출처·해시·장면 연결은 `assets/manifest.json`, 인코딩 결과는 `encounters-image-encoding.log`에 있다.

초기 독립 HTML은 큰 이미지를 중복 내장해 약 51.2MB였고 병렬 브라우저 검사에서 30초 초기 로드 제한을 넘겼다. 실패 로그를 `encounters-*-initial.log`에 보존했다. 중복 이미지 11종을 각각 한 번만 내장하고 짧은 Blob URL로 공유하도록 수정했다. 최종 HTML은 24,485,930바이트이며 이 환경에서 단독 측정한 초기 진입은 4.976초였다(`encounters-load.log`). 사용자 기기에서의 로드 속도를 보장하는 수치는 아니다. 최종 재실행은 위 표의 모든 검사를 통과했다.

최종 ZIP은 현재 실행 모듈·CSS·표시 자산·보고서·소리 자료·최신 영상만 포함한다. 원본 PNG와 과거 산출물은 Git 저장소에 보존한다. ZIP CRC와 각 포함 파일의 바이트 일치, 내장 11종 이미지의 SHA-256 일치와 외부 스크립트/스타일 요청 부재를 `encounters-package.log`에 기록한다. 패키지 자체의 해시는 이 로그가 기준이다.

`encounter-play.mp4`는 실제 브라우저 CDP 627프레임을 녹화한 21.875초, 1,912,655바이트의 무음 영상이다. 시드 2030562787의 탐험을 완주했으며 중간보스·상인·최종보스·결과 장면을 포함한다. 반복되는 중간 탭의 녹화만 생략했으며 포함 장면은 원래 속도다. 합성·조작된 게임 프레임은 없다. `encounters-video.log`가 실행 기록이고 `encounter-video-contact.png`는 실제 영상 프레임 모음이다. `encounter-final-390.png`와 최신 `encounter-*.png`·`mobile-combat-*.png`를 직접 열어 시각 검수했다.

휴식 자산 추가 중 자동 승인 검토가 base tree를 오래된 것으로 판단해 거부했다. 현재 커밋의 tree가 정확히 그 SHA이며 기존 5개 자산을 포함한다는 읽기 증거를 확인한 뒤 한 번 재시도하여 통과했다. expected HEAD와 non-force 갱신 및 fast-forward만 사용했다. 해결되지 않은 쓰기 차단은 없다. 인증 비밀이나 개인 정보는 보고서에 포함하지 않았다.

## 남은 한계와 다음 검토

관리 환경이 file:// 직접 열기를 차단하여 직접 파일 열기는 미검증이다. 내부 응답 방식의 독립 HTML 검사는 완료했다. 실물 모바일·Safari/Firefox·스크린리더·OS 큰 글자·320px 폭·실제 청취·사용자 재미 평가는 남아 있다. 최소 검수 크기는 360×640이며 해당 화면의 타일 높이는 40px로 모든 조작 영역이 44px인 것은 아니다. 자동 완주가 재미 또는 상용 품질을 증명한다고 주장하지 않는다.

실행 방법은 ZIP 해제 후 `standalone.html` 또는 README의 로컬 서버 명령이다. 다음 검토는 실제 모바일의 조작감, 사람의 첫 탐험 난이도·재미, 소리와 접근성 평가다. 롤백은 이 브랜치의 변경을 검토한 뒤 수행하며, 구버전이 새 v2 저장을 해석하지 못하므로 진행 백업을 먼저 확인해야 한다.

# 자유낙하 퍼즐과 현대 모바일 프레임

2026-10-20, 기준 fa18256. 사용자가 지적한 문제는 고전적인 황동/먹색/룬 장비창과 고정 격자다. 캐릭터 수채화·귀여운 얼굴·6층 탐험은 보존하고 조작 구조를 교체한다. 부모가 설계 보고 후 구현·검수·동일 Draft PR 갱신까지 위임했다. 승인 대기를 새로 만들지 않는다.

## 선택한 구조

외부 물리 패키지 없이 `flow.mjs`에서 원형 충돌체의 고정 1/120초 position-based 시뮬레이션을 계산한다. 월드 크기는 420×440, 42개 기물의 ID/색/특수/잔향 의미를 유지한다. 기물 반지름은 ID·seed로 결정하며 표시 도형은 충돌 원 안에 들어간다. 마찰·중력·벽·바닥·쌍별 겹침 해소로 실제 좌표가 이동한다. 같은색 접촉 그래프는 정착 좌표 거리로 만든다. 제거 후 주변 생존 기물이 빈 공간으로 움직이고 새 기물은 위에서 낙하한다. CSS jitter 또는 숨겨진 hex 판정으로 대체하지 않는다.

대안은 범용 rigid-body 라이브러리 도입 또는 격자 기반 열 낙하다. 전자는 설치·의존성 없이 구현하라는 제약에 맞지 않고, 후자는 요구한 옆 밀림/자유배치를 충족하지 않아 제외한다.

시뮬레이션은 DOM/시간/RNG 전역을 읽지 않는다. 고정 순서와 좌표 반올림으로 재현성을 유지한다. 게임 정산은 한 번 적용하고 정착 좌표를 즉시 저장한다. 렌더러는 계산한 궤적을 재생할 뿐이다. 모션 감소/탭 숨김은 궤적을 건너뛰고 같은 최종 위치를 표시한다. 정착이 끝날 때까지 타일·스킬·과충전 입력을 차단한다. 새 게임 요청은 기존 트랜잭션 경계 규칙을 유지한다.

## 규칙과 호환

기존 `neighbors(index)`는 이전 저장의 hex 경로로 남긴다. `adjacent(state,index)`가 새 좌표 보드에서는 거리 이웃, 이전 보드에서는 hex 이웃을 반환한다. 연쇄·폭탄·덩굴·잔향·선택선·소거 순서는 모두 같은 함수를 사용한다. 새 특수는 탭 색/새 ID이며 탭 좌표에서 생성한다. 기존 폭탄 전환은 ID/색/잔향/좌표를 보존한다. 새 잔향 후보는 중력 전 최초 그룹 이웃 중 최종 생존 일반 공격 타일이며 x→y→ID 정렬 최대8개다. 기존 저장은 기존 열→행 순서 그대로다. 새 잔향의 같은 탭 재귀 발동은 없다.

기존 연습 v1, 탐험 v1/v2를 그대로 복구한다. 지도/런 버전은 그대로 두고 새 연습과 탐험에 독립적인 boardVersion=1을 사용한다. 기존 저장키를 유지하고 새 게임 덮어쓰기는 기존 확인 절차를 따른다. 기존 런에는 좌표를 강제 삽입하지 않는다. 새 런은 모든 전투와 재도전에서 같은 boardVersion을 유지한다. 낙하로 생긴 새 접촉은 다음 탭 후보이며 자동 소거하지 않는다. 스킬/패널 대상 선택은 기존 배열 순서를 유지한다. 좌표/반지름/ID/경계/겹침/버전 일관성을 저장 해독 시 검증한다.

## 화면과 접근성

전투 무대 → 큰 얼굴 파티 도크 → 선명한 시안 HP바 → 밀집한 퍼즐통 → 과충전 띠. 기물은 선명한 색과 원/별/둥근네모/잎 형태, 부드러운 반투명 광택으로 구분한다. 전투 장면이 화면 배경으로 연결되며 황동·양피지 프레임을 제거한다. 360×640에서는 무대가 짧아져도 보드·스킬·피버 입력을 유지한다. 키보드 방향키는 공간 방향의 가까운 기물로 이동하고 Enter/Space로 확정한다. 모든 기물은 DOM 버튼을 유지한다.

4. 실제 브라우저에서 360×640/800,390×844,1280×900과 두 모션, 탐험/연습 전체 진행을 검사한다. 실제 낙하 영상·스크린샷을 직접 확인한다. 패키지·보고서·Draft PR을 갱신한다.

주요 위험은 미정착/겹침, 경계 hit-test, 표시와 연결의 불일치, 숨김/재시작 중 두 번 정산, 구저장 손상이다. 각각 직접 검사한다. 자동 완주를 재미 증명으로 보지 않는다.

## 참고 이미지 접근

사용자가 제공한 Library 참고 이미지 2개: 최초 두 전달은 download failed(종료1). 소비 환경 기본 경로로 한 번 재시도했으나 반환된 두 경로가 이 환경에는 없어 file does not exist(종료1). 실제 픽셀 확인 불가, 재시도 종료. 부모와 독립 검토자가 실제 확인한 설명을 설계 근거로 사용하며 원작 PNG를 게임/저장소에 넣지 않는다.

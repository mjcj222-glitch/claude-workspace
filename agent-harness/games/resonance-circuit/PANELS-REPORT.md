# 단계별 덩굴·무지개 구현 보고

기준 커밋은 `4139538cdc07b861c93aba565af82bc7e9e238c7`이다. 기존 고유 스킬·3전투·성장·저장·튜토리얼을 유지하고 새 패널만 추가했다. 모든 변경은 이 게임 폴더 안이다. 지도·유물·새 캐릭터는 넣지 않았다.

## 확정 규칙

1전투에는 새 패널이 없다. 2전투는 덩굴4개, 3전투는 덩굴4개와 무지개2개로 시작한다. 보장된 첫 연결과 그 지정 이웃13칸은 초기 배치에서 제외한다. 일반 보충 RNG와 독립된 `(seed XOR 0x9e3779b9)` 기반 LCG로 패널을 정한다. 보충 일반 타일마다 별도 난수1개를 소비하며 `[0,.08)`은 덩굴 후보, 3전투의 `[.08,.14)`는 무지개 후보다. 덩굴4/무지개2 상한 또는 덩굴의 회복색 제한에 걸리면 일반 타일로 남기고 재추첨하지 않는다. 따라서 실제 발생률은 상한과 후보 색 때문에8%/6%보다 낮을 수 있다. 시드 실험 후 후보 확률은 변경하지 않았다.

- **덩굴**: 일반 공격 타일의 `vine` 속성이다. 직접 탭은 무효이며 탭·잔향·버프를 보존한다. 연결을 막는다. 실제 소거되는 타일의 hex 이웃이거나 폭탄 피격이면 껍질만 해제한다. 같은 탭의 중복 피격이나 연결 재계산으로 본체를 지우지 않는다. ID/색을 보존한 채 중력에 따라 낙하한다. 해제만으로 피해·회복·게이지·연결수·새 잔향을 얻지 않으며 다음 행동부터 일반 타일로 연결한다.
- **무지개**: `kind: rainbow`. 일반색에서 시작하면 해당 색과 무지개만 연결하고 다른 색으로 바꾸지 않는다. 직접 탭은4색 연결을 각각 계산해 최대 집합을 고른다. 동률은 coral/gold/blue/heal, 무지개만 있어도 coral이다. 미리보기에 확정색을 표시하고 추가 팝업 없이 같은 탭 흐름으로 확정한다.
- 최초 연결의 무지개는 확정색의 공격/회복1칸이다. 폭탄에만 휩쓸리면 공격1칸이다. 제거 Set으로 중복 집계하지 않는다. 5/10 특수 생성은 최초 연결수와 확정색으로 결정하고 회복색은 생성하지 않는다. 새 특수는 새 ID다.
- 덩굴·무지개는 스킬 변환 후보와 새 잔향 대상에서 제외한다. 같은 탭에 해제된 덩굴도 새 잔향을 얻지 않는다. 고유 스킬은 기존 규칙대로 작동하며 프리즘 보너스는 확정색을 사용한다. 무지개 회복색은 프리즘을 소비하지 않는다.

처리 순서: 변경 전 보드에서 확정색/최초 연결 → 기존 ID 잔향 → 폭탄 폐쇄 → 실제 제거 Set/덩굴 해제 Set 확정 → 덩굴 해제 → 소거·새 특수 → 중력·보충이다. preview는 순수하고 tap은 같은 계산 결과를 사용한다. 42칸 중 최대4개만 덩굴이므로 유효 탭이 항상 존재하며 자동 셔플은 넣지 않았다.

## 안내·그림·저장

첫2전투/3전투 진입에 실제 덩굴/무지개를 강조하고 요청한 짧은 설명을 보드 위에 표시한다. 덩굴 해제 또는 무지개 연결을 실행하면 안내를 끝낸다. 알겠어요로 넘길 수 있고 규칙 보기5페이지에서 다시 읽을 수 있다. 재도전에는 강제 반복하지 않는다. 안내 미완료 승패에서도 종료 저장을 정상 생성한다.

기존 원본 PNG·캐릭터를 보존했다. 덩굴은 CSS 줄기와 작은 잎, 무지개는 다색 보석과 흰 별로 표현해 색 외 형태로도 구분한다. 기본 무음·reduced-motion·키보드/터치·중복 입력 방지를 유지한다. 덩굴도 포커스 가능하여 무효 사유를 읽을 수 있다.

저장 키/외부 버전1을 유지하고 `panelVersion`, `panelSeen`, `panelLesson`, `panelRng`, 타일 `vine`/`rainbow`를 검증한다. 이전 저장은 `panelVersion:0`으로 정규화하며 현재 보드/RNG/진행/버프를 보존한다. 해당 전투 재도전도 구 배치 생성기를 쓴다. 다음 전투에 진입하면 새 패널을 활성화한다. 이미3전투인 구 저장은 현재 탐험 끝까지 구 규칙이다. 패널 추가를 위해 진행을 지우거나 저장 중 보드를 재추첨하지 않는다. 저장 복구 시 패널 RNG도 그대로 복구한다.

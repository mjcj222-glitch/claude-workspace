# 속성 대형 폭탄과 진행 설계

2026-10-20. 기준 `1e2e521`. 기존 구현을 확장하는 작업이다. 총괄이 설계 보고 후 구현·검수·패키지·동일 Draft PR 갱신까지 위임했으므로 별도 승인 대기를 만들지 않는다. 변경 범위는 이 게임 폴더다.

## 선택과 규칙

새 화폐·새 스킬을 늘리는 대신 기존 연결·잔향·유물을 조합한다. Sol 6.1 검토의 직접 연결 기준과 6층 흐름을 채택한다. 기존 10개 일반 폭탄을 단순히 더 크게 그리는 안은 선택 이유가 약하다. 속성별 추가 상태·피해 버프는 넣지 않고, 범위 모양만 세 가지로 구분한다. 미리보기로 읽을 수 있는 위치 전략에 집중한다.

새 게임만 `rulesVersion: 1`을 사용한다. 보드 버전과 지도 버전은 바꾸지 않는다. 과거 hex·좌표 보드 저장은 이전 규칙으로 그대로 이어간다.

- 공격색 최초 연결 5~7개: 기존 차지와 잔향.
- 공격색 최초 연결 8개 이상: 탭에서 확정한 색의 대형 폭탄 1개와 잔향. 무지개는 확정색으로 최초 연결 수에 포함한다. 잔향·폭발로 추가 제거한 수는 생성 기준에서 제외한다.
- 회복색은 회복만 하고 차지·대형 폭탄·새 잔향을 만들지 않는다.
- 일반 폭탄은 연쇄 점화 스킬로 만들며 기존처럼 1겹 이웃을 지운다. 불꽃 대형 폭탄은 제거 전 고정 접촉 그래프의 2겹 이웃, 별빛은 가로 띠, 물방울은 세로 띠를 친다. 띠는 중심 좌표 차이가 폭탄 반지름+대상 반지름의 절반 이하인 모든 기물이다. 덩굴은 해제만 하고 같은 탭에 제거되지 않는다.
- 대형 폭탄에 별도 고정 피해 보너스는 없다. 서로 다른 색 대형 폭탄이 발동해도 각 제거 ID는 한 번만 정산한다. 기존 점화·씨앗 화약의 폭탄 횟수에는 포함하되 기존 최대 3개 상한을 유지한다.
- 기존 특수는 한 탭에 한 번만 발동하고 새 특수는 정산 후 새 ID로 생성하여 다음 탭부터 사용한다. 따라서 같은 탭 재귀 생성·재폭발은 없다. 프리즘 링크는 새 대형 폭탄의 색을 바꾸지 않는다.
- 미리보기에서 최초 연결 수, 폭발 범위와 생성될 특수 종류를 보여 준다. 대형 폭탄은 실제 원형 터치 영역 안에서 이중 테두리·큰 문양·“대형” 표시로 구분한다.

## 6층 학습 곡선

지도 v2의 방 구성을 유지한다. 안전한 선택의 의미를 보존하고 모든 층에 전투를 억지로 추가하지 않는다.

| 층 | 배울 것과 선택 | 제약 |
|---|---|---|
| 1 | 5개 차지·잔향을 익히고 8개 대형 폭탄 생성 기회. 첫 대형 생성 시 다음 탭 활용 안내 | 덩굴·무지개 없음 |
| 2 | 일반전 또는 정예전. 덩굴을 폭탄 범위로 벗기는 활용 | 새 기믹은 덩굴 하나 |
| 3 | 휴식/상인으로 빌드 조합과 체력 비용 선택 | 새로운 전투 규칙 없음 |
| 4 | 필수 중간보스. 무지개로 8개 연결을 만들고 잔향으로 장막을 해제 | 이미 배운 폭탄·덩굴 복습 |
| 5 | 회복 또는 유물로 최종 준비. 현재 빌드에 맞는 선택 설명 | 새로운 전투 규칙 없음 |
| 6 | 장막·무지개·폭탄·3탭 정산을 종합하는 최종전 | 신규 규칙 대신 기존 조합 시험 |

첫 보드는 무한 재추첨 없이 정착된 접촉 그래프를 한 번 분석해 8개 연결을 배치한다. 덩굴 단계에는 덩굴 옆 소형 폭탄, 무지개 단계에는 두 색군을 잇는 무지개를 마련한다. 좌표와 RNG는 바꾸지 않고 초기 색·패널만 구성한다. 첫 2~3탭 생성→폭발 경로를 검증한 뒤 리필은 기존 난수로 풀어 준다.

첫 유물은 긴빛 렌즈·잔향 방울·꽃잎 변압기의 핵심 선택에서 제시한다. 다음 보상은 선택한 빌드를 보완하는 유물을 우선하되 후보·순서는 시드와 보유 유물로 결정한다. 일반전은 2개, 정예·중간보스는 3개 중 하나를 고른다. 기존 저장은 기존 후보 수·순서를 유지한다. 선택·재로드·중복 클릭이 보상이나 체력 비용을 두 번 적용하지 않아야 한다.

연습도 새 게임에 같은 규칙을 적용하며 1전투 기본, 2전투 덩굴, 3전투 무지개의 기존 구성을 유지한다. 정확한 적 체력·반격은 여러 고정 시드와 폭딜/잔향/회복 정책을 비교하여 최종 보고서에 기록한다.

## 낙하와 선택 장면

권위 있는 물리 계산과 최종 좌표는 변경하지 않는다. 렌더 전용 보간 모듈에서 좌표·각도 궤적을 단조 cubic으로 보간해 구간 경계 속도 변화를 줄이고 마지막 속도를 0으로 만든다. 보간은 구간 범위를 넘지 않으며 원래 좌표와 RNG를 수정하지 않는다. left/top 매 프레임 갱신 대신 transform을 사용한다. 재생 시간은 대체로 460~720ms로 제한하여 이전 최대 850ms보다 입력 대기를 늘리지 않는다.

선택 장면은 기존 원화를 고정 배경으로 쓰고 독립적인 빛줄기·잎·작은 입자가 서로 다른 주기로 움직인다. 보상은 작은 유물 문양, 휴식은 빛·잎, 상인은 반딧불을 사용한다. 그림 전체의 반복 줌·큰 흔들림은 하지 않는다. 모달의 선택 버튼은 즉시 사용 가능하며 움직임은 입력·정산을 소유하지 않는다. reduced-motion과 숨김에서는 정적 상태로 즉시 전환한다.

## 구현·검증 순서

1. 변경 전 게임 126개와 하네스 검사를 실행하고 현재 좌표 보드 저장 fixture를 보존한다.
2. 순수 규칙 모듈과 폭발·생성·속성 중복·회복·저장 버전·보상 일회성 검사를 추가한 뒤 엔진·진행·저장을 연결한다.
3. 렌더 보간과 실제 보드 안내, 선택 장면 레이어를 구현한다. 모션 변경·숨김·취소는 기존 0/1회 정산 경계를 유지한다.
4. 고정 시드에서 기존 규칙/새 규칙과 여러 전략의 승률·턴수·남은 체력·대형 폭탄 활용을 비교한다. 자동 정책은 사람의 재미를 대신하지 않는다.
5. 실제 브라우저 전체 완주, 저장 복구, 중복 입력, 모션·숨김 전환, 짧은 화면, 낙하 영상과 정적 캡처를 확인한다.
6. standalone/ZIP 무결성, 문서·로그·영상, Draft PR을 갱신한다. main 병합·수동 배포·추가 결제는 하지 않는다.

# 보고 역할 (Report)

입력: 조사/검증/개발 결과.
결과를 다음 순서로 요약한다.
- 연구 날짜 및 주제
- 오늘 새롭게 확인한 내용 (중복/변화 없음도 명시)
- 핵심 주장별 출처와 검증 상태
- 수행한 코드/테스트, 성공/실패
- 비용/사용량/승인 대기
- 남은 질문과 다음 연구 주제(최대 3개)

출력: `agent-harness/reports/YYYY-MM-DD/<topic-id>.md`. 파일을 실제 저장하지 않았다면 **저장했다고 주장하지 않는다**.
공개 GitHub로 게시하기 전에 개인정보·계정·비공개 정보 포함 여부를 검사한다.

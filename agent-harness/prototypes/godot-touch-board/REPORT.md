## 자산과 남은 항목
승인된 새 원본 atlas를 이 실행 환경에 materialize하고 직접 픽셀 확인 후 적용했습니다. 캐릭터/표적은 이번 자체 제작 벡터 시안, 효과음은 단계별 합성 PCM(6동시음, 마무리음/착지음)입니다. 사람의 청취 평가를 대신하지 않습니다. 사용자 원본 참조 이미지는 지원 다운로드2회 모두 `download failed`로 끝나 파일이 없었으며 더 시도하거나 우회하지 않았고 공개 저장하지 않았습니다.

Web 검증은 Chromium154의 SUID sandbox helper 구성 오류로 실행 전에 중단됐습니다. `--no-sandbox`나 권한 변경을 하지 않았습니다. [정확한 오류](evidence/browser-blocker.txt). 이는 앱 실행 실패이며 자동 승인 검토 거부는 아닙니다. Linux 빌드와 소리 있는 영상은 완료했고, Android 실물·Safari/Firefox·Web 실제 플레이와 재미 평가는 남았습니다.

기술 판단: 완전한 rigid-body 정착 대신 연속 원형 지지점+0.44초 제어 낙하를 사용합니다. 고정 격자 매칭이 아니지만 생존 패널이 옆으로 미끄러지며 압축되는 연출은 사용자 판단이 필요합니다. 색 충돌은 시작점 접촉거리/ID 우선의 첫 변환을 보존하고, 이미 지운 패널을 재정산하지 않습니다. [규칙](docs/RULES.md) · [모션 비교/비용](docs/MOTION.md). 지도·상점·유물·저장·파티·보스·적 패턴·피버는 제외했습니다.

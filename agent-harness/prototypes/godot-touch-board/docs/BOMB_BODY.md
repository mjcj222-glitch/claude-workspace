# 큰 폭탄 본체와 선택 판정

기준: 001548a. 폭발 반경 98/164, 공급/피해/회복/연쇄, 적/탐험/물리는 유지한다.

선택한 작은 설계: 새 원본 SVG 두 개로 광택 있는 구형 금속 폭탄을 만든다. 일반 폭탄 표시 반경은 30, 대형 표시 반경은 48 논리 px이며 일반 패널 37보다 대형 본체가 크다. 물리 반경은 둘 다 기존 37이다. 실루엣을 전경에 확대하면 옆 블럭과 클릭이 겹치므로, 대형 몸체를 뒤에서 먼저 그리고 일반 패널을 앞에 둔다. 앞에 보이는 일반 패널의 클릭이 우선이며, 노출된 큰 몸체 외곽도 선택된다. 대형끼리 겹치면 실제 마지막에 그린 높은 ID가 우선한다. SVG 가장자리의 작은 투명 여백은 클릭용 여유 범위다.

같은 표시 반경을 렌더·클릭·선택 윤곽에 사용하고 축소/낙하/절제 모드에서도 유지한다. 물리/접촉은 원래 반경 37이다. 보드 바깥의 장식 외형은 벽 뒤로 클립되며, 보이지 않는 바깥 부분은 클릭되지 않는다. 패널을 보드 안쪽으로 순간 이동시키거나 배치를 바꾸지 않는다.

검증: 겹침 우선순위/외곽/취소/경계/동일 폭발 계획 RED→GREEN, 실제 작은 창 및 확대·축소 입력, 상단 공급과 낙하 중 동일 크기, 정상 두 캐릭터의 일반/대형 폭탄, 기존 회귀와 독립 시각 검토. 기존 크기와 실제 비교 화면/소리 포함 짧은 영상을 남긴다. 물리 크기와 시각 크기를 혼동하거나 그림만으로 새 피해 범위를 주장하지 않는다.

## 실제 결과 · 2026-10-21

| 대상 | 표시 반경 / 지름 | 물리 반경 | 실제 폭발 반경 |
| --- | --- | --- | --- |
| 일반 패널 | 37 / 74 px | 37 px | 해당 없음 |
| 일반 폭탄 | 30 / 60 px | 37 px | 98 px |
| 대형 폭탄 | 48 / 96 px | 37 px | 164 px |

위 값은 논리 좌표다. SVG 투명 가장자리 때문에 불투명 금속 몸체는 지름 약 93 px이며, 큰 반경 링만 키운 결과가 아니다. 대형은 자주·금색 띠/리벳과 붉은 보석, 일반은 청색 강철 몸체로 구분한다. 본체를 낙하 중에도 같은 크기로 표시하며 폭탄에는 기존 착지 찌그러짐을 적용하지 않는다. 소거될 때의 축소 연출은 유지한다.

선택은 보이는 앞쪽 일반 패널을 우선하고, 그 뒤 노출된 대형 몸체 테두리를 고른다. 일반 폭탄의 보이지 않는 물리 반경 37까지 클릭 영역을 늘리지 않는다. 대형끼리는 높은 ID가 나중에 그려지고 선택에서도 우선한다. 밀집 시 대형 몸체 일부는 이웃 뒤에 가려진다. 벽 근처에서 확대분 최대 11 px가 보드 마스크 뒤에 가려질 수 있으며, 그 바깥 부분은 클릭되지 않는다. 물리 접촉·중력·범위는 확대하지 않았다. 모든 투명 픽셀에 대한 정밀 알파 클릭 판정을 구현했다는 뜻은 아니다.

## 실행한 검증

- 기존 회귀를 포함한 48개 스크립트: 실패 0. 규칙, 유물, 탐험/상점/전투, 타격 동기화, 자연 낙하 중간 경로, 반복 보충과 저장된 보충 실패 회귀를 포함한다. 원래 테스트가 생성하는 과거 증거 파일은 보존하고 이번 결과는 별도 폴더에 복사했다.
- 새 본체 검사 15개: 실패 0. 노출된 반경 37~48 부분 선택, 이웃 우선권, 크기·그리기 순서, 보드 경계, 취소, 미리보기/실행, 확대율 0.5/1/1.25의 역변환을 검사했다. 기존 코드에서 외곽 선택 실패를 먼저 확인했다.
- 실제 X11 포인터 입력: 720×1080, 360×640, 390×844 창에서 각각 24개 검사, 실패 0. 밀집 배치·벽·선택 외곽·취소·실제 폭발 164·리셋을 확인했다. 이 화면은 명시적인 고정 배치 fixture다. 절제 모드 전후 동일 몸체 영역의 픽셀 차이도 세 크기 모두 없었다.
- 정상 자동 플레이: 중간 HP/골드/충전/보드 주입 없이 노아 19회 소거(HP 28, 17 G), 리오 23회(HP 20, 18 G)로 한 구역을 완주했다. 일반/대형 폭탄 모두 위쪽 유입과 실제 낙하 중 크기를 기록했다. 이전 001548a의 동일 입력과 모든 소거 시작 ID·제거 ID·피해·폭발·공급이 일치했고 최종 HP·골드·유물·충전·예약도 같았다.
- `board_motion.gd`, `board_rules.gd`, `board_bombs.gd`, `board_audio.gd`, `board_combat.gd`, `board_area_session.gd`는 001548a와 바이트가 같다. 물리나 게임 수치 수정은 없다.
- 독립 검토: 소스의 그리기/선택 순서와 실제 정상 플레이·낙하·밀집·작은 창·마지막 영상 프레임을 검토했으며 최종 차단 사항이 없었다. 전체 영상의 사람 청취 평가는 하지 않았다.

첫 녹화 실행은 테스트 스크립트의 혼합 들여쓰기 파싱 오류로 게임 시작 전에 실패했다. 테스트 파일 들여쓰기만 수정한 뒤 파싱 검사와 두 정상 녹화를 완료했다. 첫 고정 배치 화면의 임시 HP/상한 불일치는 fixture의 상한만 맞춰 최종 화면과 입력 검사를 다시 저장했다. 실패 로그를 숨기지 않고 남겼다.

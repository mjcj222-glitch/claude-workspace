# 폭탄 통합과 타격 소리·효과 강화

기준 커밋: `2089b392`. 기존 캐릭터, 유물, 한 구역 탐험, 적 수치, 색 변환 핵, 자연 낙하는 유지했다. 이번 규칙 확장은 별도 원형 폭탄만 다룬다. 자체 합성 음원과 코드 도형을 사용했으며 새로운 이미지·외부 음원·다운로드는 없다.

## 현재 핵과 폭탄의 차이

부모가 2026-10-21 전달한 [공식 FAQ 조사](https://crashfever.com/faq/2024080226319/)는 CP 기본 6연결, SCP 기본 12연결, SCP의 폭탄 생성과 주변 파괴 폭탄을 구분한다. 정확한 크기별 반경은 확인되지 않았다. 현재 물감핵은 주변을 자기 색으로 바꾸고 연결을 소거하는 자체 규칙이다. 원작의 CP/C스킬 또는 폭탄과 같다고 주장하지 않는다. 아래 획득 방법, 연쇄 처리와 반경은 **우리 프로토타입의 시험 설계**다.

| 항목 | 일반 폭탄 | 대형 폭탄 |
|---|---:|---:|
| 실제 원형 폭발 반경 | 98 논리 px | 164 논리 px |
| 물리 충돌 반경 | 37 | 37 |
| 금속 외형 반경 | 28.86 | 34.78 |
| 내부 문양 | 네 갈래 | 여섯 갈래·이중 표식 |

- 직접 일반 패널 6/12개, 렌즈 보유 시 5/11개의 기존 핵 생성 보상은 그대로다. 긴 연결 자체에 폭탄을 중복 지급하지 않는다.
- **강화핵을 실제로 발동한 행동**은 다음 보충에서 폭탄 하나를 준비한다. 여러 강화핵도 한 행동에 하나다. 응축 렌즈를 소유하면 대형 폭탄을 준비한다. 노아와 번짐 안료의 강화핵 설치도 다음 소거에서 이 경로로 이어진다. 설치·변환 자체는 피해를 주지 않는다.
- 이미 난수로 만들어진 첫 pending 몸체의 종류만 변경한다. ID·충돌 반경·공급 개수·난수 소비는 동일하다. 새 몸체는 기존 상단 유입과 중력 시뮬레이션을 거친다. 생존 패널 재배치나 추가 몸체 삽입은 없다.
- 폭탄은 무속성이다. 단독 탭, 다른 폭탄의 원형 범위 또는 핵의 접촉 범위로 기폭한다. 같은 색 연결의 대상·경유, 스킬 변환/설치 대상에서는 제외한다.
- 폭풍은 행동 시작 스냅샷의 **중심점 거리**로 판정한다. 범위의 일반 패널은 색과 무관하게 소거, 하트는 회복, 기존 핵과 폭탄은 연쇄 발동한다. 전체 연쇄 대상과 원형 범위를 누르는 동안 미리 본다. 놓으면 동일 계획을 실행한다.
- 제거·회복·발동은 ID마다 한 번이다. 일반 공격 패널의 기존 피해 1, 하트 회복 2와 회복 상한은 유지한다. 폭탄 객체 자체는 피해·약점·직접 일반 개수에 포함되지 않는다. 약점은 실제 제거되는 일반 패널의 변환 후 색을 따른다.
- 새 보충 폭탄은 현재 계획에 들어가지 않으며 닿았다고 자동 기폭하지 않는다. 핵과 폭탄 패널은 기존 규칙대로 전투 사이에 유지되지 않는다. 렌즈의 효과는 보상·상세·이벤트·상점에 모두 표시한다.

## 소리와 연출

기존 한 번의 `take_impact()` 이벤트와 표시 HP 시점을 유지했다. 소거→전달→국소 명중→피해 숫자/HP 반응의 동기화는 바뀌지 않는다. 하트는 영웅 방향 모트와 별도 맑은 음색을 쓴다.

- 24단계 소거 음색을 캐시했다. 15번째에 음높이가 되감기던 반복을 없애고 24단계에서 상한을 둔다. 일반/강화 핵, 일반/대형 폭탄은 별도 합성 폭발음이다.
- 여섯 음성 안에서 소거용 4개, 핵/폭탄 1개, 최종 명중 1개를 분리한다. 명중은 빠른 어택, 내려가는 저역 바디, 짧은 질감과 약점 강조를 결합한다. 재생 중 PCM 생성은 하지 않는다.
- 파편·링·전달체 예산과 별도 효과 RNG를 유지한다. 큰 연결의 파편 속도·굵기, 핵 종류별 파동, 명중점의 짧은 별/이중 충격파/적 반동을 강화했다. 카메라와 물리 좌표는 흔들지 않는다. 보드 전체 섬광은 없다.
- 절제 모드는 반동·섬광·파편을 억제한다. 음소거는 새 음뿐 아니라 재생 중 꼬리음도 즉시 중단한다. 연출 수명은 준비 상태·낙하·다음 입력의 조건이 아니다.

## 실행한 검증

- 기존 구역/캐릭터/성장/적/입력/접촉/중간 경로/반복 보충/저장된 보충 실패 재현/타격 동기화 포함 **47개 스크립트**에서 최종 실패 0. 원래 실패 로그와 수정 후 개별 재검사를 함께 보존했다.
- 신규 검사: 폭탄 규칙 27개, 실제 main 공급/정착/다음 입력/리셋 10개, 캐시/음소거/명중 메타데이터/효과 예산 17개. 원형 경계 안팎, 변환 후 약점 진입/이탈, 하트·핵 연쇄, 중복 제거, 신규 공급 보호, 취소를 포함한다.
- 실제 OS 포인터 입력: 360×640, 390×844 각각 23개 검사 실패 0. 이 화면의 폭탄·체력·모달 상태는 명시된 fixture이며 정상 보상 획득 증거와 구분한다.
- 자원·보드·충전 강제 주입 없는 정상 자동 진행: 노아 19소거, HP 28, 17G 승리, 대형 폭탄 3회 사용. 리오 23소거, 일반 폭탄 1회 사용 후 승리. 두 경로 모두 결과에서 새 선택으로 돌아갔다. 자동 조작은 사람의 재미·균형 검증이 아니다.
- 독립 소스/실제 화면/로그 검토에서 발견한 렌즈 설명 누락을 보상·상세뿐 아니라 구매 화면까지 수정했다. 최종 차단 결함 없음. 검토자가 실제 음을 듣거나 실기기를 플레이한 것은 아니다.

## 소리의 객관적 확인과 한계

마스터 볼륨은 올리지 않았다. 동일 26초 입력의 통합 음량은 이전 −27.8 LUFS, 수정 −26.1 LUFS로 약 1.7 LU 높다. 단순 음량 효과를 구분할 수 있도록 수정 음향을 1.7dB 낮춘 별도 비교 파일도 남겼다. RMS를 맞춘 원시 파형/스펙트럼 그림은 음색과 어택 변화의 분석 자료이며 청취 만족도를 입증하지 않는다.

처음 합산 피크 상한이 1을 넘는 것을 발견해 hard clamp 대신 합성 파형 정규화를 적용했다. 수정 후 여섯 음성의 보수적 합산 피크 상한은 0.9685다. 최종 정상 녹음의 채널 유지 디코드 피크 −9.213dBFS, RMS −32.541dBFS, full-scale/NaN/Inf 샘플 0. 개별 전후 영화와 짧은 미리보기도 디지털 클리핑 샘플 0이다. 원음의 소리 존재/피크와 **사람의 실제 청취 평가는 구분**한다. 후자는 아직 하지 못했다.

## 실시간 비교

같은 클라우드 native llvmpipe 환경에서 기록된 정상 입력 7회를 버전별 3번, A–B–B–A–A–B로 실행했다. 정책 탐색·스크린샷·출력 파일 I/O를 재생 구간에서 제외하고 공통 측정 래퍼만 사용했다. 고정 프레임 영상은 별도다.

| 지표 | 이전 | 수정 |
|---|---:|---:|
| 일반 소거 commit→ready 중앙값 | 865ms | 849ms |
| 일반 소거 관측 범위 | 798–1008ms | 808–1326ms |
| 핵 소거 중앙값 | 1421ms | 1413ms |
| 보드 소거 선택 첫 draw 중앙값 | 20.410ms | 20.468ms |
| 보드 소거 선택 첫 draw 최대 | 68.297ms | 77.091ms |
| 모든 버튼 포함 첫 draw 최대 | 68.297ms | 131.289ms |

수정 후 지도 후보/입장에 100ms를 넘는 반응과 한 차수의 느린 꼬리가 있었다. 분포가 겹치므로 **성능 향상 또는 완전한 동등을 단정하지 않는다**. 0.6–1.0초 목표도 모든 일반 소거에서 달성했다고 하지 않는다. 비교한 21개 상태의 계획·피해·자원·RNG와 물리 좌표는 같았다. 마지막 행동의 새로운 폭탄 종류 한 개만 의도된 차이다. 고정 프레임 전후 영화의 명중 7회는 피해·약점·action clock이 일치했다.

별도 수정 버전만의 사전 입력 19회 native 재생도 승리했고 실제 폭탄 3회가 동작했다. 비교 가능한 이전 폭탄 행동은 없으므로 전후 속도 향상의 증거가 아니다. 숫자와 프로파일 원본은 `evidence/impact-strength/performance/`에 있다.

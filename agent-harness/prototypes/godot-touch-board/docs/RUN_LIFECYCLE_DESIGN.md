# 로컬 단일 탐험 수명주기 설계 / 2026-10-22

기준 767f87a, 별도 local/chroma-run-lifecycle 작업 폴더. 기존 후보·Library 파일 불변. 최신 추가 승인: 검증 후 기존 PR3 브랜치 푸시와 기존 자동 preview는 허용. 수동 배포/설정 변경은 없음. 전투/물리/폭탄/음향 구현 불변.

## 선택한 방식과 불변식
- 정상 새 탐험은 새 시드를 선택한다. 명시적 --seed=N은 리셋도 같은 시드로 재현한다. --no-save 및 레거시 sandbox/short-run은 저장 비활성. 자동화는 --seed=20261021 --no-save를 명시한다. 저장 테스트만 --save-dir=/tmp/... 전용 경로를 쓴다.
- 매 프레임/애니메이션 직렬화 대신 안정된 행동 완료 시점 체크포인트. 출발·지도 선택/입장·보상/상점/휴식/이벤트 거래·스킬 적용·낙하와 적 반격 완료 후 저장한다. 보드 누름/미리보기/모달 누름은 저장하지 않는다. busy/enemy_attack/stalled는 저장하지 않는다. 중간 종료는 마지막 완료 체크포인트로 돌아간다고 화면에 알린다.
- 같은 seed 및 RNG.state(정수 정밀도 유지), 캐릭터·고유 보드 ID/위치/종류/색·next_id, 스킬/HP/골드/유물, 지도 방문/지급 기록, 상점 재고/이벤트 진행/보상 후보/offer_serial, 고정된 적 의도와 정산 가드를 복구한다. 복구 중 initialize_board/start_fight/prepare_turn을 호출하지 않는다.
- 입력 소유자·미리보기·애니메이션·효과 재생은 복구하지 않는다. 복구 후 모든 입력은 새 press부터 시작한다. 스킬 선택 UI는 닫지만 이미 확정된 스킬 효과/충전은 유지한다.
- 저장은 명시된 필드만 담는 버전1 포맷. 기본 Variant 자료형만 직렬화한 payload와 SHA256 envelope, 크기 제한, 타입/범위/보드 ID/지도 경로/자원 일관성 검증. 객체 역직렬화 금지. 임시 파일 flush/close/검증 후 같은 파일시스템 rename. 유효한 직전 체크포인트 backup 유지. OS 전원 손실 내구성까지 보장하지 않는다.
- 손상/잘림/버전 불일치 파일은 삭제하지 않는다. 유효 backup을 명시적으로 복구하거나, 새 탐험 확인 후 전체 이전 저장 폴더를 archive로 이동한다. 불명확한 형식을 추측/마이그레이션하지 않는다. 저장 실패는 화면에 남기고 성공으로 표시하지 않는다.
- 승패 완료 시 별도 closed 장벽을 원자적으로 먼저 기록한다. 장벽이 있으면 backup에서도 진행을 부활시키지 않는다(장벽 손상도 보수적으로 차단). 새 탐험은 확인 후 이전 폴더를 보관하고 새 슬롯으로 시작한다.
- 시작 시 이어하기/새 탐험. 진행 중 리셋 및 남은 저장 위 새 탐험은 명시 확인. 취소하면 원래 진행 유지. 확인 전 새 보상/시드로 기존 저장을 덮지 않는다. 외부 통신/계정/개인정보 없음.

## 구현 순서
1. 저장 포맷/검증/원자적 교체/backup/closed/보관 모듈 및 부정 테스트.
2. 컨트롤러 안정 경계와 새 시드, 재개 동작; 작은 수명주기 overlay와 확인 입력.
3. 별도 프로세스 checkpoint/resume 및 동등 입력 비교, 거래 경계/중단/승패, 회귀 runner 고정 seed 명시.
4. 실제 작은 창 입력과 정상 자동 진행, 전체 기존 회귀. 로그/한계를 기록한다. 최초 로컬 한정에서 후속 승인으로 검증 후 PR3 브랜치 푸시 허용으로 변경되었다.

## 검증 기준
- 다른 정상 seed, 명시 seed 반복 같음. 기존 고정 seed 결과 보존.
- 교차 프로세스 재개: seed/RNG/패널/스킬/경제/지도/적 의도 완전 일치; 이어진 합법 행동 후 미중단 실행과 동일.
- reward/shop/rest/event/skill/board/boss 각 경계의 거래 중복 방지. held input/취소/연타/애니메이션 중 저장 금지. 재개 stale release 무효.
- 손상/잘림/checksum/미지원 버전/잘못된 타입/중복ID/잘못된 경로는 안전 거부. backup 복구 사실 표시, 원본 보존. 임시파일만 남는 경우 마지막 commit 유지. closed 뒤 backup 부활 금지.
- 실제 정상 승리/패배→재시작, 정상 입력 경로 및 52개 회귀+기존 전체 창 검사. 저장 테스트는 임시 경로만 사용. 전체 희귀 시드·실물 Windows/모바일·전원차단 시뮬레이션은 별도 한계.

# 전신 캐릭터와 피니시 후보 (2026-10-22)

이 작업은 a4d67d4의 규칙과 저장 상태를 보존하는 시각 후보다. 앞선 원화는 정교한 일러스트였지만 픽셀 캐릭터 요구와 하단 전신 표시를 충족하지 못했다. 앞선 피니시도 시각적 완성으로 판정하지 않는다.

## 적용 범위
- 공식 이미지 생성 편집으로 만든 후보 B를 사용한다. 붉은 리오와 보라 노아의 전신 실루엣을 보존한다. 확대 생성 PNG이며 네이티브 32×48 제작물이라고 주장하지 않는다.
- 런타임 atlas 영역과 nearest 표시로 전신을 하단에 배치한다. 보드 영역, 상단 상시 주인공 금지, 스킬/저장/폭탄 규칙은 유지한다.
- 축적 에너지의 성장과 압축, 두꺼운 방향성 방출, 적 주변 충격파와 파편, 적 반동을 강화한다. 기존 0.28초 예비 동작과 0.24초 적중 유지, 피해 1회 판정은 유지한다.
- 합성 저/고 연쇄 연출 시험과 실제 정상 입력 플레이 영상을 구분한다. 작은 창에서 전신/전조/보드 가독성을 확인한다.

## 검증과 전달 경계
순수 연출 변경이 RNG나 전투 결과를 소비하지 않아야 한다. 테스트 모형은 실제 CanvasItem 그리기 API를 지원해야 하며, 실패 기록을 보존한다. PCM 및 인코딩 오디오의 클리핑을 확인하되 실제 기기 청취로 표현하지 않는다.

먼저 후보 이미지와 실제 화면·소리 영상을 전달한다. 현 단계에서 커밋·푸시·Windows 패키징·신규 고유능력은 진행하지 않는다. 엄밀한 픽셀 격자 품질과 사람의 미술/체감 평가는 자동 테스트 통과와 별개다.

## 실제 진행
- B 원본 바이트를 보존한 atlas를 적용하고 전신 종횡비를 유지했다. 하단은 보드 아래에 머문다. 대기 중 nearest 샘플링 크기가 흔들리지 않도록 확대 진동을 제거했다. 별도 포즈 프레임은 추가하지 않았다.
- 전신 렌더러 60개 검사와 두 캐릭터 × 다섯 상태의 360×640 실제 창 캡처를 완료했다. 피니시 후보 검사(bank16, 신규23, quality34, chain/boss23, impact19)가 통과했다. 최초 draw_polyline 테스트 모형 누락 실패 로그는 보존했다.
- 저장 검사 첫 실행에 잘못 붙인 --short-run에서는 구역 체크포인트 검증이 실패했다. 제품 코드를 변경하지 않고 기본 구역 모드, 명시적 seed841, 별도 /tmp 저장 경로로 실행한 검사는 34개 통과했다. 두 로그를 evidence/fullbody-candidate에 보존한다.
- 실제 플레이 영상은 정상 초기화·press/release·자연 보충을 사용한 첫 전투 발췌다. 360×640 실행 창과 달리 MovieWriter 출력은 내부 viewport720×1080이다. 합성 저/고 연쇄 영상과 구분한다. 이번 후보에서 전체 회귀 및 장시간 완주·교차 프로세스 비교는 재실행하지 않았다.

## 후속 검토와 검증
위 후보 전달 후 전체 회귀53개 명령, 두 창64개씩, 정상 두 승리/한 패배 및 저장100자식 프로세스(전체 연속/재개 비교는2회)를 추가 실행했다. 자세한 결과와 해당 소스 해시는 evidence/fullbody-validation에 보존한다. 정상 플레이에서 거의 사라진 파편의 퇴화 다각형 렌더링 오류를 발견했다. 기계적 검사가 통과해도 이 렌더링 오류를 성공으로 처리하지 않는다.

부모 시각 검토는 전신 B를 유지하되 피니시는 여전히 부족하다고 판정했다. 두 번째 교정은 하단 주인공 쪽의 축적점, 고강도에서 적보다 큰 방사형 빛의 실루엣, 바깥으로 튀는 방향 파편, 뒤따르는 넓은 충격파와 단일 큰 피해 숫자다. 저강도와 크기 대비를 유지하고 보호막/전조 영역을 보호한다. 효과의 개수와 수명, 기존 판정 시각은 늘리지 않는다. 퇴화 다각형을 방지하며 새 코드와 실제 게임 자산을 사용하는 짧은 연출 시험을 따로 검증한다. 새로운 정상 플레이 증거와 합성 연출 시험을 섞지 않는다.

# 연금술 계기판 품질 보강

기준 `86a827d5aa0f31dd05705ce7b4121341552b254d`. 기존 광택 패널·초상·젤리와 맞추어 청록 유리, 절단 모서리와 금색 베벨, 상부 광택·하단 두께를 UI 전체에 적용했습니다. **밸런스2/8, HP/피해/회복, 보상·경제·중력은 유지**했습니다. 새 전투·이미지 생성·효과음 재설계는 없습니다.

- 스킬·보상·경로·상점·승패·유물 소켓의 재질을 통일하고 눌림/준비/선택/비활성을 구분했습니다. 기존 모든 터치 사각형과 보드 표시/역변환 좌표를 유지했습니다.
- 하단 초상·이름·스킬 제목과 정확한 충전 N/요구 수·분할 표시를 구성했습니다. 잿빛 보석의2회 충전·예약도 표시합니다. 준비 직후0.65초 광택 후 작은 상부 빛만 움직입니다.
- 성공한 스킬 실행에만0.5초 얼굴 확대·대각선 컷인을 표시합니다. 원본 초상 일부를 확대하며 보드 밖 하단에 머뭅니다. 타겟 선택·취소로는 발동하지 않고 입력/물리/준비 상태를 기다리게 하지 않습니다.
- 실제 고정 접촉의 짧은 곡선 연결, 고유 제거ID별 파편·핵 링과 방향성 피해/하트 궤적을 구성했습니다. 큰 파괴 숫자와 피해는 분리하며 피해값은 기본+약점의 확정 합계, 회복은 유효/초과/전체를 구분합니다. 새 선택 중에는 잔여 효과가 미리보기 설명을 덮지 않습니다.
- 시각 RNG를 분리했습니다. 과거와 같은 다음 보드를 보존하기 위해 게임 RNG의 고정14회 clear 예산만 별도 호환 함수로 남겼으며, 입자 수/궤적의 난수는 시각 RNG만 사용합니다.

## 글꼴과 원본

공식 Black Han Sans1.001을 제목/큰 파괴 수에, Pretendard 공식1.3.9 Medium/SemiBold를 본문·숫자에 사용합니다. 원본 바이너리를 변환하지 않았고 전체 OFL·저작권·출처/버전·SHA256을 보존했습니다. Black Han에 없는 기호는 Pretendard 런타임 fallback을 사용합니다. 공식 다운로드는 모두 성공했으며 다른 경로나 권한 우회는 없었습니다. [전체 글꼴 고지](../assets/fonts/README.md), [원본 코드·아트 범위](../assets/UI_ART.md). 기존 초상/젤리/패널/유물 원본은 수정하지 않았고 잘린 초상으로 전신을 만들지 않았습니다.

## 실시간 성능 한계

같은 클라우드 Godot4.6.3/llvmpipe 소프트웨어 렌더링/Dummy 오디오에서 같은 입력을 사용했습니다. **이번 관측은 느려졌습니다.** 아래는 중앙값/최댓값이며 캡처 I/O와 자동 결정 CPU가 섞인 한 번의 정상 진행 비교입니다. 이후 실행은 컷인 캡처도 추가돼 엄밀한 통계 벤치마크가 아닙니다. 고정30fps 영상은 이 실시간 성능 증거로 사용하지 않았습니다.

|---|---:|---:|---:|
| 수락된 누름→표시 | 21 | 16.250/58.253ms | 26.812/298.097ms |
| 기존 핵 없는 확정→보충 완료 | 13 | 1.193/1.554초 | 1.435/2.169초 |
| 기존 핵 포함 확정→보충 완료 | 2 | 1.320/1.517초 | 1.489/1.671초 |

입력21개 중2개가100ms를 넘었고 일반 소거0.6~1초 목표도 전부 충족하지 못했습니다. [실시간 원자료](../evidence/quality/live-comparison.json). 초기 보드 CPU 미세검사135개에서 계획 계산 중앙638μs, 접촉선 캐시545μs였지만, 이는 늦은 프레임의 원인을 분리한 측정이 아닙니다. 렌더링·플랫폼 스케줄링과 복잡한 후반 계획의 기여는 추가 분리가 필요합니다. 시각 검사는 통과했지만 반응속도 목표 달성으로 표시하지 않습니다.

**기존 결함도 미해결입니다:** seed23·정예·고의 회피·소거20·HP2의4.008초 정체. [손실 없는 재현 상태](../evidence/balance/stall-reproduction/summary.json)를 보존했으며 제한 연장/강제 이동/물리 수정으로 숨기지 않았습니다. Windows/Web 최신 빌드, Android/iOS 실물, 물리 오디오 청취와 사람의 재미는 미검증입니다. AAC 비무음(mean -36.4dBFS, peak -12.8dBFS)만 확인했습니다. 기존 ZIP은 이번 버전이 아닙니다. Library 전달은 부모가 담당합니다.

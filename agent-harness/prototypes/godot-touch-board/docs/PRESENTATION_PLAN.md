# 소거 표현과 유물 아이콘 — 실행 범위

기준: 원격/로컬 `be5c003943857f21732c60cd7ea54538deb096c7`, 시작 시 작업 트리 깨끗함.

- 목적: 실제 제거한 패널 수와 핵 발동 수를 구분해 읽히게 하고, 작은 소거보다 긴 소거/핵 연쇄가 강하게 느껴지도록 한다. 유물3종을 아이콘으로 식별하고 보유 아이콘에서 설명을 읽는다.
- 총괄: main/UI 연결, 보유 설명 입력 격리, 대표 영상·실시간 비교·보고. visuals: 원본SVG3종과 아이콘 렌더 helper/공개 라이선스. render_env: 제거ID 중복 방지 카운터와 한정된 입자/고리 모듈·실패 우선 검사. rules: 보유 설명/모달 통합 검사. review: 독립 코드/화면 검토.
- 카운트: 확정 계획의 제거 ID와 원래 패널을 사용해 한 ID당 한 번 증가한다. 하트도 포함한다. 핵 활성화는 별도 숫자이며 피해 배율은 추가하지 않는다. 취소/스킬은 카운트하지 않는다. 리셋은 효과와 숫자도 초기화한다.
- 연출: 큰 숫자, 짧은 최종 합계, 색 파편·로컬 빛·확장 고리와 핵 전용 파동. 효과 예산을 제한하고 게임 RNG와 별도 RNG를 쓴다. 현재 기본 파편의 게임 RNG 호출은 보존해 보충 색/물리가 달라지지 않게 한다. 연출 종료를 입력/물리 완료 조건에 넣지 않는다.
- 유물: 안료병/렌즈/잿빛 보석의 같은 테두리 스타일 원본 아이콘. 카드 이름·수치 옆에 표시. 하단 보유 strip은 충분한 터치 영역을 갖고, 설명을 여닫는 해제는 보드로 전달하지 않는다. 스킬 팔레트/보상 중에는 중첩 입력을 받지 않는다.
- 검증: 카운터/하트/핵 중복/취소·리셋, 설명/스킬/보상 모달과 작은 창 실제 OS 입력. 기존 규칙·성장·미리보기·중간 경로·반복 보충 회귀. 같은 작은/긴 소거의 실제 벽시계와 프레임을 별도로 측정하고, 영상은 고정 프레임임을 표시한다.
- 증거: 작은 소거, 긴 핵 연쇄, 아이콘 보상·보유 설명을 포함한 짧은 영상과 화면. 최종 상태를 읽을 시간을 두고 회색 종료 화면 전 녹화를 끝낸다.

물리/접촉·성장/보상 수치·새 전투 단계·오디오 재설계는 변경하지 않는다. 추가 구매/계정/배포/보안 변경 없이 새 프로토타입만 PR #3 브랜치에 저장한다. Library 전달은 부모가 담당한다.

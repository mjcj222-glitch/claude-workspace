# 대연쇄와 속성 보호막 통합 계획

사용자 목표: 자동 공격 대신 판을 크게 준비하고 직접 터뜨리는 두 캐릭터, 한 보스의 명확한 공략, 원본 도트 캐릭터와 시청각 연결. 기존 저장·유물·원판 폭탄·물리를 보존한다. 세부 설계와 구현은 사용자 위임으로 진행한다.

## 설계
- Rio: 목표 색 선택 후 일반 패널을 누르면 그 원래 색의 모든 일반 패널을 목표 색으로 변환. 같은 색 선택은 무효. 하트/핵/폭탄 보존. 안료 소유 시 다음 1회 소거 보급의 일반 패널도 목표 색. 공격/행동 자동 실행 없음.
- Noa: 일반 패널 하나에 기존 핵 설치를 유지하고 그 색으로 다음 2회 소거 보급 일반 패널 고정(안료: 강화핵+3회). 하트/기존 특수 패널과 보급 종류는 보존. 고정 낙하 중 소거는 충전하지 않음. 고정이 끝난 뒤 3회(잿빛 예약이면2회) 정상 소거 필요. 남은 보급 횟수 표시. 보급 중 RNG는 기존대로 소비 후 색만 적용.
- Boss: 진입 때 보드에서 가장 많은 일반 색(동률 낮은 인덱스) 보호막12. 해당색 제거 개수만큼 내구 감소, 해당색이 없으면 유효 소거당1 감소. 보호막 잔존 중 피해 절반(내림), 파괴 소거는 원래 피해+6. 한 번만 생성; 보스 HP48/반격/전조는 유지. 하트로 파괴한 경우 보너스도0: 기존 하트 무피해 규칙. 미리보기와 실제 피해를 동일한 순수 계산으로 제공.
- 저장2: 남은 고정 보급·색 및 보호막 내구/색 저장. 저장1 읽기에서는 고정0, 이미 진행 중인 보스 보호막0을 추가해 소급 장벽 생성 금지. 원본은 읽기만으로 덮어쓰지 않음; 다음 정상 체크포인트에서2로 저장. 구버전은2 안전 거부.
- 표현: 제거 위치→적 위치 궤적, 적중 숫자, 보호막 파편. 짧은 원본 도트 하단 대기/스킬/반응. 표현 RNG 분리, 추가 입력 잠금 없음, 효과 감소 지원.

# 보충 이동 수정 체크포인트 — 2026-10-21

기존 생존 패널의 전역 재배치와 목적지 직선 보간을 제거했습니다. 새 규칙·UI·자산을 추가하지 않았습니다. **경로 회귀 검사는 통과했지만 실시간 속도 목표는 미달입니다.** Windows 패키징은 사용자 지시에 따라 중단했고 이 수정의 새 실행 ZIP은 만들지 않았습니다.

## 원인과 수정
`5819dd8`의 `pack()`은 생존 패널을 빈 배치에 다시 놓아 기존 지지보다 전체의 낮은 공간을 우선했습니다. 실제 23/24번 두 패널 제거 재현에서 생존체 24개가 좌우로 이동하고 최대 가로 이동이 546.23px였습니다([원시 재현](../evidence/motion-fix/repacking-reproduction.json)). `main.gd`의 0.44초 보간은 중간 충돌을 검사하지 않았습니다. 이전 새 패널의 출발점은 이미 상단이었습니다. 문제를 새 패널의 중간 생성으로 진단하지 않았습니다.

수정은 실제 위치·ID를 유지한 120Hz 중력/원 충돌 계산입니다. 실제 지지가 유지된 패널은 고정하고 지지가 사라지면 다시 움직입니다. 신규 패널만 위쪽 입구에서 추가하며, 입구는 현재 표면의 빈 공간을 보고 고릅니다. 목적지 좌표는 만들지 않습니다. 현재 중심을 그대로 렌더합니다. READY는 완전한 sleep 대신 작은 잔여 속도를 짧게 확인한 뒤 멈추며, 4초 시뮬레이션 제한을 넘으면 리셋 가능한 중단 상태입니다. [설계 및 한계](MOTION.md).

## 검증
- 순수 규칙44검사, 입력, 최초 배치, 실제 씬 검사 통과. 실제 씬은 기존 고정 1.25초 가정을 제거하고 5초 이내 상태 전환을 검사합니다. 이 변경을 속도 목표 통과로 해석하지 않습니다.
- 두 개 제거 / 중앙 묶음 / 왼쪽 기둥의 각 1/120초 위치와 ID 기록. 출발점 보존, 위쪽 유입, 바닥 지지체 이동0px, 중간 겹침 최대0.033px, 샘플 사이 선형 상대경로 겹침 최대0.050px, 최대 한 스텝9.167px, 충돌 이력 없는 옆 이동0건. [요약](../evidence/motion-fix/path-summary.json), [전체 경로](../evidence/motion-fix/path-traces.json).
- 명시적 두 지지점 유지/한 지지점 제거 검사, 10회 부분 보충 검사 통과. 보충 시뮬레이션0.858–1.167초, 전체 몸체 경계와 최종 비중첩 확인. 임의 모든 보드에 대한 보장은 아닙니다.
- 독립 검토 에이전트가 소스와 동일 경로·10회 반복 검사를 다시 확인하여 통과했습니다. 코드 변경은 하지 않았습니다.
- 실패 보존: 초기 stub 미완료 경로, 8회 충돌 보정의 겹침, 순환 입구의 왼쪽 쌓임과 상단 중단, 24회 보정의0.22–0.46px 잔여 겹침 로그가 이 증거 폴더에 남아 있습니다. 현재 표면에 따른 입구와 최대128회 조기 종료 보정으로 해결했습니다. `stall-*.json`은 이전 실패 상태입니다.
- `cycles-diagnostic.log`의 Godot 실행은 XDG 쓰기 경로 없이 실행해 사용자 로그 디렉터리 생성 실패/프로세스 종료가 발생했습니다. 기존 승인된 `/tmp` XDG 환경을 읽은 실행은 정상입니다. 권한이나 보안 설정은 바꾸지 않았습니다.

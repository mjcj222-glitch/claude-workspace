# 속성 약점과 예고 강타 검증

기준 소스는 `f2d7cd1be792da888d72350dc747229b2ebef664`입니다. 세 전투·경로·골드·상점·유물과 자연 낙하는 유지하고, 약점 피해와 마지막 적의 예고 강타를 추가했습니다. HP와 공격 수치는 승인된 실험값 그대로이며 밸런스 확정값이 아닙니다. 새 아트·폰트·효과음·지도는 추가하지 않았습니다.

## 적용 규칙

실제 소스에는 적별 공격색 정의가 없었습니다. 기존 네 공격 패널의 문양과 색을 사용해 첫 적 **불꽃(빨강)**, 안전 적 **새잎(초록)**, 정예 적 **번개(노랑)**, 마지막 **강타 수호자·물결(파랑)**로 구분했습니다.

한 행동의 피해는 `기존 기본 피해 + floor(약점 일반 패널 수 / 2)`입니다. 전체 연쇄에서 실제 제거된 고유 ID와 제거 직전 최종색을 사용합니다. 변환 후 약점색은 포함하고, 변환 전 색·남아 있는 변환 패널·하트·핵 객체·이번에 생성한 핵은 제외합니다. 기존 소스의 일반 패널당 기본 피해1, 핵 객체 자체 피해0, 하트당 회복2를 보존했습니다. 연쇄별로 나눠 반올림하지 않으며 저항이나 비약점 페널티는 없습니다.

마지막 적은 가능한 강타10→4와 일반6을 교대합니다. 강타는 **한 행동에서 약점 일반2개 또는 공격 일반8개**를 제거하면 그 턴 동안 약화됩니다. 추가 연쇄의 일반 패널도 포함하지만 행동끼리 합산하지 않습니다. 예정된 강타 턴 시작의 실제 정착 보드를 같은 소거 계획기로 검사하고, 이미 가능한 소거가 없으면 그 턴 전체를 일반6으로 고정합니다. 스킬이나 미래 보충을 기회 검사에 가정하지 않습니다. 활성 강타 중에는 스킬을 사용해 조건을 만들 수 있지만 스킬 자체·미리보기·취소는 경감이나 행동을 얻지 않습니다. 둘째 적의 기존 직접4개 조건은 그대로입니다.

누르는 시점에 보드·유물·약점·예고를 값으로 복사하고 미리보기와 실행에 같은 계획을 씁니다. 피해·회복·핵·충전·예약·낙하가 끝난 후 전환하며 셋째 행동에서도 처치가 반격보다 우선합니다. UI는 기본+약점 피해, 일반/약점 수, 회복을 구분합니다. 두 줄 예고를 위해 보드 표시만18px 아래로 옮겼고 물리 좌표와 전체 선택 영역은 유지했습니다. 입력 좌표의 역변환도 같은 표시 영역을 사용합니다.

## 정상 보드 진행과 난이도 한계

두 초기 시드×양 경로×기존 세 유물 쌍×두 정책으로 **24회** 진행했습니다. 중간 보드·HP·골드·충전 주입이나 실패 구출 없이 정상 초기화·보충·상점을 사용했습니다. 24회 모두 승리했고 상태 감사2722개에 오류가 없었습니다. [원본 기록과 집계](../evidence/elemental/normal-audit.json).

보스70턴에서 강타41턴, 일반29턴(기회 없는 fallback5턴), 경감 성공39회, 실제 반격46회·총228피해·사망0이 기록됐습니다. 실제 반격은 경감4피해24회와 일반6피해22회였고, **실패 강타10피해는 이 정상 표본에서 나오지 않았습니다.** 실패·패배 분기는 결정적 검사에서만 확인했습니다. 첫 적은3~4행동, 둘째는2~5행동, 마지막은6~9행동에 끝났습니다. [원본에서 계산한 범위·실제 피해 분포](../evidence/elemental/normal-derived.json)도 보존했습니다. 약점과 기존 핵/스킬을 적극 사용하는 자동 정책에는 쉬운 표본이며, 사람에게 도전적인 난이도나 재미가 검증됐다고 볼 수 없습니다. HP를 몰래 올리거나 유리한 보드를 만들지 않았습니다.

## 실시간 측정과 미검증

[별도 실시간 실행](../evidence/elemental/live-summary.json)은 Godot4.6.3, 클라우드 Xorg/llvmpipe 소프트웨어 렌더링, Dummy 오디오에서 측정했습니다. 자동 선택 계산과 캡처 I/O가 섞인 정상 실행이며 전용 벤치마크가 아닙니다.

| 측정 | 표본 | 최솟값 / 중앙값 / 최댓값 |
|---|---:|---|
| 수락된 누름→표시 | 21 | 14.108 / 15.966 / 19.087ms |
| 기존 핵 없는 소거 확정→보충 완료 | 13 | 692.081 / 1179.689 / 1494.341ms |
| 기존 핵 포함 소거 확정→보충 완료 | 2 | 1140.093 / 1334.459 / 1528.825ms |

일반 소거의0.6~1초 목표는 전부 충족하지 못했습니다. 반격·모달이 뒤따르면 보충 완료와 다음 입력 시각도 다릅니다. 고정30fps MovieWriter 영상은 이 실시간 성능의 근거가 아니며 다른 보드의 이전 수치와 개선율을 비교하지 않습니다.

Android/iOS 실물, Windows 실행, 현재 소스의 Web 실행, 물리 오디오 청취, 사람의 재미/난이도는 미검증입니다. 기존 ZIP은5819dd8의 오래된 자료이며 이번 실행 파일로 표시하지 않았습니다. 새 의존성·계정·보안 변경·외부 배포는 없고, Library 전달은 부모가 담당합니다.

# 전신 B · 최종 피니시 V2 검증

## a4d67d4 대비 변경

붉은 리오와 보라 노아를 원본 B atlas의 전신으로 표시한다. 얼굴 크롭을 제거하고 하단 기존 영역 안에서 종횡비/nearest/정수 위치를 유지한다. 확대 생성 픽셀풍 이미지이며 네이티브 저해상도 스프라이트나 개별 포즈 프레임 애니메이션은 아니다.

제거 에너지는 하단 주인공 쪽에 모인다. 마지막 한 방에서는 왼쪽 여백을 따라 올라가는 에너지, 굵은 방출, 큰 방사형 스파크, 방향성 파편과 뒤따르는 충격파, 한 번의 큰 피해 숫자를 사용한다. 고강도 용머리 피니시의 오른쪽 잘림은 화면 영역에 맞춘 의도적 확장이다. 보호막 설명/전조와 보드를 보호한다. 평면적인 삼각형 도형 느낌은 남아 있으며 상용 미술 완성으로 주장하지 않는다.

3회 유효 소거의 축적과 피해 1회 정산, 0.28초 준비/0.24초 적중 유지, 미리보기/적 행동/보상/저장/유물/캐릭터 기술/폭탄 37·48 및 폭풍 98·164 규칙은 변경하지 않았다. 효과 파편이 0에 가까워질 때 발생한 렌더러 다각형 오류를 두 위치에서 수정했다. 게임 RNG를 추가로 사용하지 않는다.

## 실행 검증

- V1 후보 검증: 기존52개+전신 렌더러1개 명령 모두 통과. 교차 프로세스100회 실행으로 전체 연속 대 분할 재개를 두 번 비교했고 리오33소거/노아21소거 승리의 상태 해시가 각각 일치했다. held/busy/적 반격 중단 복구, 새 시드 다양성/명시적 시드 결정론도 통과. 로그와 해당 소스 해시는 evidence/fullbody-validation에 보존한다.
- V2 방사형 피니시 반영 후 53개 명령 모두 통과. 별도 bank16, 타이밍/RNG/효과감소/오디오23, quality34, chain/boss23 검사 통과. 두 실제 창360×640/720×1080에서 각각64개 OS 입력 검사 통과.
- 정상 입력 리오2301 안전길15소거 승리 HP29, 노아841 위험길21소거 승리 HP30. 소모전 정책 리오2301은21소거 패배와 재시작 확인. 보드/HP/충전 주입을 하지 않았다. 자동화 전략의 작은 표본이며 승률/재미 판단이 아니다.
- V2 정상 플레이가 드러낸 별도 콤보 파편 오류를 한 줄의 subpixel guard로 수정한 후, 같은 리오·노아 입력을 다시 완주했다. 두 최종 로그 모두 오류/경고0, 오디오 정리 잔여0. 수정 후 feedback32, bank16, interruption19, hit Area21/short21도 통과. 53개 전체 묶음은 이 마지막 한 줄 전 실행이며, 그 뒤에는 영향 받는 검사와 두 완주를 재실행했다.
- 실제 컨트롤러 검사는 축적 준비/적중 중 반복 press/release/cancel이 무효임을 확인하고, 단 한 번의 피해와 적중 유지 후 보상/반격, 중복 콜백, 불안정 상태 저장 거부/복구를 검사한다.

## 실패와 한계

이전 오류 로그를 제거하지 않았다. 초기 모형의 draw_polyline 미지원, 촬영 스크립트 이름 충돌, overlay 갱신 누락, 잘못된 short-run 저장 검사 호출, 파편 퇴화 오류 및 중단한 재실행을 각각 기록했다. 잘못 촬영된 미디어는 전달하지 않으며 로컬 중간 자료로 보존한다. subpixel 경계 smoke는 선택한 시점에서 수정 전 오류를 재현하지 못했으므로 red/green 재현 증거로 부르지 않는다. 수정 전후 같은 정상 입력 로그가 실제 결함의 근거다.

Library의 8초 low/high 영상은 실제 자산을 쓰는 합성 피니시 시험이며 정상 플레이가 아니다. 별도의 실제 보스전 영상은 정상 입력의 원본 트레이스와 함께 제공한다. MovieWriter는 내부720×1080/60fps를 기록하며 실제 기기 성능 측정이 아니다. 오디오는 실제 엔진 출력 파일을 분석했지만 물리 스피커/헤드폰 청취를 하지 않았다.

실제 보스 영상은 seed2301 리오의 연결10+12+19=41개 축적, 단일 피해36, 보스 HP48→12와 보호막12→0을 보여주는11.5초 발췌다. 원본 정상 실행도15회 소거 승리 HP21로 끝났다. 촬영 드라이버의 기존 보호막 대응 기술 전략이 headless 완주 전략과 달라 HP29 결과와 구분한다. 오류0/오디오 정리0, 피크−10.2475dBFS/클리핑0이다. actual-boss-media.json에 영상 및 런타임 소스 해시가 있다.

Windows 후보는 정확한 새 커밋에서 별도로 만든다. ZIP/PCK 무결성 및 Linux에서 같은 PCK 로드/저장 재개 검증은 Windows 실행 검증을 대신하지 않는다. 기존 후보와 Library 파일은 보존한다. GitHub 하네스 CI, 로컬 Godot 검증, Vercel 자동 프리뷰 상태를 구분하며 Godot Web 실행이나 수동 배포를 주장하지 않는다.

# 작은 한 구역 구현 계획

승인:24f9f19의 두 캐릭터와 전투를 유지하며 전투/휴식/선택형 이벤트/상점/보스를 실제 분기 지도에 연결한다. 한 구역만, 새 아트·초상 전송·대량 적·영구 성장·외부 배포 없음.

## 설계와 가설

8개 노드: entry(첫 적), rest, event, safe, elite, extra(추가 정예), shop, boss.
연결: 출발→entry→(rest|event)→(safe|elite)→(shop|extra|boss), extra→(shop|boss), shop→boss. 최단3전투, 추가 정예를 고르면4전투. 지도에서 인접한 다음 노드만 후보로 고르고 별도 입장으로 원자 확정한다. 들어간 노드는 재방문/역행/취소 환급 불가. 미선택 경로·보스까지 남은 선택과 현재 HP/G/유물/충전을 볼 수 있다.

전투 능력치는 기존 그대로다: 첫24HP/4피해, 안전36HP/7→3·5, 정예/추가정예44HP/8→4·6, 보스48HP/가능한10→4·6. 약점·현재 가능한 소거 확인·적 사망 우선·자연 보충을 그대로 쓴다. 같은 정예 패턴 재사용을 명시하며 새 적이라 주장하지 않는다.

첫 승리4G, 안전4G, 정예/추가정예8G와 미보유 유물 선택1회. 미보유가 없으면 자동 대체4G와 확인 화면이며 중복 지급 불가. 보스 뒤에는 지급 없음. 휴식은3G/최대8HP(상한30), fullHP/잔액부족은 소비 불가, 무료 지나가기 가능. 이벤트는3G를 내고 화면에 명시된 첫 미보유 유물 즉시 획득 또는 무료로2G 수령 중 하나만. 비용/결과 선공개, 미보유 없으면 유물 교환 비활성. 상점은 기존4G/최대8회복과8G/남은 유물1개, 각1회이며 구매/방문 모두 선택이다. 모두 보유 시 품절·없는 유물 판매 금지. 이것은 밸런스 가설이며 최종 수치가 아니다.

모든 비전투 지점/새 전투에서 HP/G/캐릭터/유물/충전진행/요구량/Ash예약 유지. 회복은 명시된 거래만, 스킬 무료 충전 없음. 새 전투만 기존 initializer로 새 보드 생성; 핵/변환은 이전 보드에서 이월하지 않는다. reset/결과 복귀는 새 선택으로 모든 런 상태 초기화. 중단 저장/재개 및 최신 사용자 실행 패키지는 별도 미완료 항목이다.

## 범위와 설계 근거
`SYSTEMS_STATUS.md`의 남은 유물 조합 부족 및 “유물 후보/적 전조/후반 패턴을 소량 확장” 항목을 선택했다. 기존 문서에 이 유물의 이름/수치는 없었으며, 구체 효과는 이번에 설계했다. 과거 파티 영입안은 현재 단독 캐릭터 설계에 적용하지 않는다. 기존 저장/재개 구현은 유지한다.

구현 전 정한 범위: 원래 첫 보상 3종은 유지하고, 이후 승리 보상에 방어와 회복의 교환 선택 하나를 추가한다. 수호 꽃잎 소유 시 직접 연결한 하트 3개 이상이 현재 direct4/slam 조건을 충족한다. 기존 조건 충족과 중첩되지 않으며 일반 공격에는 적용되지 않는다. 하트 회복은 직접/간접 제거 모두 개당 2에서 1로 줄고, 하트 피해는 계속 0이다. 추가 적/캐릭터/전투 수치/물리/폭탄/음향 변경은 없다.

불변 조건: 유물 최대 3개, 중복 획득/구매 불가, 스킬이나 간접 폭발 하트만으로 방어 불가, 미리보기와 해석 일치, RNG 재굴림 금지, 기존 미선택 보상과 상점 재고 보존. 보상 전용 유물이며 상점에 직접 판매하지 않는다. 3칸이 찬 후 기존 4G 대체 보상은 동일하다. 이제 전체 후보가 4개이므로 문구는 “유물 칸 가득”으로 바로잡았다.

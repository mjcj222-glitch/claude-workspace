# 고유능력 후속 설계 · 아직 미구현

2026-10-22. 현재 아트/3회 축적 교정을 독립 검토한 뒤 구현할 작은 후보다. 이 문서는 출시된 능력 설명이 아니다. 새 유물은 우선 추가하지 않는다.

근거: 공식 https://crashfever.com/faq/faq_cat/faq6/ 직접 확인: 시작색을 요구하는 액셀체인과 다른 색 연결을 허용하는 멀티체인은 다르다. 기본3탭 후 공격하며 카운트 스킵은 선택사항이다. 공식 faq5는 이번 executor 재조회에서 점검 페이지였으므로 직접 확인으로 기록하지 않는다. 부모 조사에서 액티브/어빌리티/C스킬 구분이 전달되었다. 개별 캐릭터 수치 및 원작 영상 청취는 이 구현의 검증 근거로 삼지 않는다. CHROMA 노아는 원작의 동명 캐릭터와 별개다.

- 리오 후보: 매 턴 첫 빨강 일반 패널 시작 연결에 한해, 그 동색 연결과 실제 접촉한 다른 색 일반 패널을 최대2개 포함. 추가 패널에서 재귀 확장은 하지 않는다. 안정ID 순으로 결정하고 미리보기에서 구별한다. 하트·특수는 확장 대상으로 포함하지 않는다. 색은 실제색 유지, 약점/보호막도 실제 제거색으로 산정한다. 무조건 전체색 연결이나 추가 행동은 아니다. 취소/스킬은 사용권을 소모하지 않는다.
- 노아 후보: 매 턴 처음 코어/강화핵을 실제 기동한 연결에서 축적 공격 +2 및 다음 반격 경감1. 같은 연결의 여러 코어에도 한 번만 적용, 방어는 턴이 끝나면 만료하고 기존 조건부 예고/꽃잎 계산 뒤 최소0으로 적용한다. 코어 자체의 없는 피해를 포기한다는 비용은 만들지 않는다. 기존 코어1개+일반낙하2회 고정 액티브는 유지한다.
- 공통: 첫2회 사용 여부와 추가 축적/방어도 저장되어야 한다. 버전3 저장에서 새 능력을 소급 지급하면 안 되므로 마이그레이션 정책을 먼저 결정한다. 첫 턴 중간 저장은 해당 턴 사용 완료로 간주하는 보수적 정책을 후보로 둔다. 추가탭·재충전·자기반복으로 무한 사용하지 않는다.

구현 전 수용 검사: 실제 접촉/시작색/최대2개 경계, 취소 후 재선택, ID순 결정론, 미리보기=실행, 코어 여러개 한 번만, 꽃잎/보호막/피해0/하트, 첫2회 저장 재개/중단 복구, 기존버전 보존, 두 캐릭터 정상 플레이. 현재 아트/리듬 자료를 먼저 검토할 수 있게 별도 변경 단위로 진행한다.

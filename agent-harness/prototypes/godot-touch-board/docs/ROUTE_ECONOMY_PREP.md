# 경로·골드·상점 확장 준비

기준: 로컬/원격 `61a8bf18a29c94781ff0abc7fbb4581da378f784`, 작업 트리 깨끗함을 확인했습니다. 사용자 승인 범위는 두 번째 전투의 안전/정예 선택, 승리 골드, 두 번째 승리·유물 선택 뒤의 작은 상점, 기존 마지막 전투입니다. 퍼즐·중력·스킬·유물·기본 UI는 유지합니다. UI/폰트 보강, 넓은 지도, 새 화폐/추가 콘텐츠는 제외합니다. 세부 계약을 받기 전 가격·보상량·정예 수치·상품 효과를 정하지 않습니다.

## 기존 연결 지점

- `scripts/board_run_session.gd`: `finish_refill()`의 처치 우선/승리 보상 전환, `choose_relic()`의 보상 확정, `begin_next_fight()`의 다음 전투 상태 유지가 진행 상태의 단일 소유 지점입니다. 골드 지급·소비와 경로/상점 방문 상태도 이 층에서 검증하여 UI의 중복 클릭이 자원을 다시 변경하지 않도록 합니다.
- `scripts/board_combat.gd`: `start_fight()`와 `prepare_turn()`이 적 수치·예고를 결정합니다. 정예 경로의 정확한 수치/규칙은 받은 계약에서만 적용하며 기존 경감 기회와 처치 우선순위는 유지합니다.
- `scripts/main.gd`: `_advance_fight()`가 기존 일반 초기화기로 보드를 만들며 체력/충전/유물/예약을 유지합니다. `press/release/move_pointer/cancel_input/reset_board`의 모달 소유권·새 누름/해제·전환 잠금·원자적 리셋에 경로/상점을 연결합니다. 세션 외부에 재화 계산을 중복하지 않습니다.
- `scripts/board_ui.gd`: 현재 보상/다음 전투/종료 모달 영역에 경로·상점 선택과 골드 표기를 추가합니다. 작은 창 제어 크기와 보드 입력 차단을 유지하며 새 아트/폰트를 받거나 제작하지 않습니다.

## 계약 수신 뒤 실행 순서

1. 경로별 전투/골드, 승리 한 번 지급, 구매 조건/중복 방지, 방문/건너뛰기, 자원 유지와 리셋을 결정적 단위 검사로 먼저 고정합니다. 세부 계약에 없는 수치는 넣지 않습니다.
2. 기존 세션·다음 전투/모달 흐름에 최소 구현하고 기존 검증 범위를 유지합니다. 새 단계 때문에 바뀌는 흐름의 기대값만 계약에 맞게 확장합니다. 기존 성장 샌드박스와 규칙/물리 코드는 보존합니다.
3. 안전/정예 정상 시드 진행, 골드 수지·상점 구매/건너뛰기, 무효/취소/이중 입력·리셋, 기존 규칙/유물/중간 경로/반복 보충과 작은 창 검사를 실행합니다. 독립 코드·시각 검토와 소리 포함 짧은 정상 흐름을 남긴 뒤 PR3 브랜치만 커밋/푸시·원격 해시 대조합니다.

## 확인할 실패 경계

- 승리 완료 또는 오래된 콜백 반복으로 같은 전투의 골드/보상을 두 번 지급하지 않음.
- 경로·상점 전환 중 이전 손가락의 놓기와 추가 손가락이 새 선택/보드 소거로 이어지지 않음.
- 잔액·보유/판매 상태를 검증한 동일 구매만 한 번 확정하며 취소/초점 상실은 골드를 소비하지 않음.
- 경로/쇼핑 중 체력·충전 요구량·진행·유물·잿빛 예약을 의도 없이 초기화하지 않음.
- 재시작은 재화·경로·판매/방문·보상 상태와 기존 효과/시계/입력 후보를 함께 초기화함.

## 승인 범위와 실험 수치

플레이어30/30, 스킬 준비, 무유물로 시작합니다. 전투1 HP24/3행동마다4피해, 전투2 HP36/경감과일반5공격교대, 전투3 HP48/6·8공격교대입니다. 수치는 밸런스 가설이며 기존 퍼즐 규칙은 유지합니다. 두 승리에서 미보유 유물을 하나씩 선택하고 명시적인 다음 전투를 누릅니다. 세 번째 승리는 종료이며 패배/재시작을 제공합니다. 지도·상점·통화·파티·영구저장·추가 아트·새 소리는 제외합니다.

전투2의 경감 턴은 시작 보드에 합법적인 직접4개 묶음이 있을 때만7→3조건을 예고합니다. 직접 선택ID만 세고 연쇄 추가 제거는 제외합니다. 기회가 없으면 그 턴은5공격으로 고정합니다. 하트와 기존 핵도 직접 그룹에는 포함됩니다. 잿빛 유물의 별도 조건은 여전히 직접 일반 공격6개입니다.

## 전환 불변식

유효 소거 계획은 누르는 순간 고정하며 미리보기와 실행이 같습니다. 기존 회복/충전/유물과 중력 보충을 마친 뒤 처치를 먼저 판정합니다. 살아 있는 적에게 세 번째 행동을 마쳤을 때만 예고 피해를 한 번 적용합니다. 반격 표시는0.45초이며 기존 낙하·소거 준비 시간에 포함하지 않습니다. 승리 보상은 새 유물을 직전 결과에 소급하지 않습니다. 전투 간 생명·충전·요구량·유물·미사용예약을 유지하고 일반 초기화기로 새 보드를 만듭니다. 실제 탐험에는 첫7개색보정이 없습니다.

리셋은 모든 탐험 상태에서 유일하게 허용되는 전환 입력입니다. 세션·물리·선택·모달후보·카운터/파편·반격시계·재생 중 음성을 함께 초기화합니다. 타이머/비동기 지연 콜백을 새로 도입하지 않습니다.

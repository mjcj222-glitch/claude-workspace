# 출발 캐릭터 선택과 한 판의 정체성

승인 범위: 기존 3전투·분기·상점·유물·물리·타격 동기화를 보존하고 두 캐릭터의 출발 선택과 결과 복귀를 연결한다. 추가 기획 승인 대기나 새 그림 제작 없이 현재 클라우드 작업 트리에서 수행한다.

## 짧은 설계

- **리오 / 변환사**: 현재 능력을 그대로 유지한다. 색을 고른 뒤 접촉 그래프에서 가까운 일반 공격 패널 최대4개를 변환한다. 번짐 안료 보유 시5개. 소거와 즉시 피해는 없다.
- **노아 / 핵술사**: 준비된 스킬로 일반 공격 패널1개를 같은 색의 물감핵으로 바꾼다. ID·위치·반경·색을 유지하며 새 패널 생성/낙하/피해/회복/행동 소비는 없다. 다음 수동 소거에서 기존 핵 규칙으로 기동한다. 하트·기존 핵은 설치 대상이 아니다. 색 선택 메뉴가 없다.
- 노아의 번짐 안료는 **시전 시 심는 핵만 일반핵(접촉1단계)→강화핵(2단계)**으로 만든다. 기존 핵에 소급하지 않는다. 응축 렌즈는 기존 직접 일반 공격 패널5/11 생성 기준, 잿빛 보석은 기존 직접6개 예약과 다음 스킬 후 요구2회를 양쪽에 동일 적용한다. 심은 핵 자체는 일반 패널 피해/약점/직접 생성 수에 포함되지 않는다.
- 두 능력 모두 처음 준비, 사용 후3회 유효 소거로 충전(예약 소비 시2회), 스킬 자체는 소거/충전/턴/경감을 발생시키지 않는다. 적 예고는 스킬로 재판정하지 않는다. 스킬 미리보기와 실행은 같은 동결 계획을 쓴다.
- 실제 앱은 출발 선택 화면으로 시작한다. 카드 선택 후 명시적 출발로 한 명을 확정하고 중간 변경은 불가하다. 첫 전투에 능력별 짧은 운용 안내를 표시한다. 승패 결과에 선택 캐릭터를 표시하고 선택 화면으로 돌아간다. 리셋도 완전 초기화 후 선택 화면으로 돌아간다. 기존 단독 세션 fixture API와 sandbox는 별도 유지한다.
- 두 번째 캐릭터는 기존 지원 초상화를 공유하며 **임시 초상**임을 선택 화면에 명시한다. 새 전송/그림/비용은 없다. 기존 컷인은 실제 성공한 능력 이름을 표시한다.

## 주요 실패 방어

출발 카드 선택이 출발 버튼 release로 이어지지 않도록 화면 serial과 포인터를 검증한다. 출발/전투/결과 전환의 같은 위치 반복 입력을 방어한다. 모든 reset은 세션·기술 provenance·pending impact·음향을 비우며 음소거/절제 선호는 유지한다. 스킬 설치는 canonical damage/예고를 건드리지 않고, 획득 유물은 다음 스킬부터 적용한다. 물리 파라미터·준비 조건·timeout은 변경하지 않는다. 봇 성공을 재미나 최종 밸런스의 검증으로 표현하지 않는다.

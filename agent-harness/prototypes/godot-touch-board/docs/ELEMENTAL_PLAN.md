# 속성 약점·강타 전투 구현 계획

**Goal:** 기존 짧은 탐험에서 초반 약점을 배우고 마지막 예고를 보고 한 행동을 계획하도록 합니다.
**Spec:** 부모의2026-10-21확정계약, 기준f2d7cd1be792da888d72350dc747229b2ebef664. 수치는최종밸런스가아닌검증가설입니다.
**Architecture:** 고유ID·유효색의피해는Rules,적약점·턴예고는Combat,선택snapshot/자원은Session,표시는UI가소유합니다. 기존경로/골드/상점/유물/입력/물리/아트/음원은보존합니다.

## 승인 규칙과 최소 결정

- 기존일반피해1/하트회복2/핵자체피해0을확인했습니다. 일반패널고유ID가실제제거될때의최종색으로W를세고전체행동한번만floor(W/2)를기본피해에더합니다. 하트/핵/새핵/변환만되고남은패널은W0. 저항/배율/패널기준/유물조건변경없음.
- 기존소스에는적별고정색이없었습니다. 승인된서로다른4약점을기존공격팔레트순서로연결합니다: 첫적불꽃0,안전적새잎1,정예적번개2,마지막물결3. 새색/문양/자산은만들지않습니다.
- 마지막HP48유지. 첫/짝수턴은현재합법소거중W>=2또는일반제거>=8이가능할때만강타10→4. 없으면그턴전체일반6. 홀수턴일반6. 조건은한행동의전체일반소거이며행동간누적없고성공은턴동안유지. 스킬/미리보기/취소/무효는행동/경감에영향없음. 기존둘째적직접4조건(하트/핵포함)은그대로.
- 완료후처치가세번째반격보다우선. 실제보충완료후만다음예고. 보드/유물/약점/intent를누름시점값으로고정하며놓을때재계산하지않습니다.
- UI는기존약점문양/한국어이름과'약점패널2개당피해+1',정확한기본+보너스와조건충족을표시합니다. 필요한두줄예고를위해보드표시만18px아래(30,268)로옮기며660×530전체와물리좌표를유지합니다. 보드끝798/결과행시작799로패널/상단유입을가리지않고최소22논리px를유지합니다. 입력역변환도동일상수를사용합니다.
- PR3새프로토타입만저장. main/옛게임/병합/배포/유료서비스/계정/보안변경,새아트/긴지도/폰트작업은제외합니다.

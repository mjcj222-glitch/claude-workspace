# Original Rio and Noa character illustration

`rio-noa-sheet.png` is an original generated transparent RGBA illustration,
1447×1087, made for CHROMA. Left: Rio with teal beret and paintbrush. Right:
Noa with violet star hood and staff. No game asset was extracted or traced.

This is detailed pixel-style illustration, not a hand-drawn 32×32 sprite sheet.
The supplied source file is preserved unmodified. The previous renderer selected
separate face/bust atlas regions, drew at integer logical coordinates with
nearest filtering, and applied bounded breathing, readiness, skill, cheer and
hit motion. These were whole-bust transforms and original sparkle overlays;
they are not separately drawn facial or skeletal animation frames.

The character artwork is supplied as part of the project's original assets.
No third-party artwork license or attribution is required for this generated
asset. Existing unrelated asset licenses remain unchanged.

## Approved full-body candidate B

`rio-noa-full-body-b.png` is the approved enlarged generated coarse-pixel
candidate, retained byte-for-byte at 1447×1087 RGBA. It is not a native 32×48
sprite sheet. The current renderer selects the full Rio and Noa silhouettes
from this atlas and fits their original aspect ratios inside the existing
footer. Nearest sampling and integer logical-pixel placement are used; no
resized or repainted derivative file is stored. Idle, ready, skill, cheer and
hit use bounded presentation transforms and sparkles, not separate drawn poses.
The previous detailed illustration remains preserved as an earlier candidate.
